## 新增 A · t3 引入青碧 `#0e8fb0` 取代淡紫 `--run` 的裁决

**① 是否越出方案三原始定义（"亮色底不动 + 半透明玻璃 + 彩色光斑 + 白内描边 + 紫色品牌色不变"）？**
—— **一半在授权内，一半越界。**
- 把青碧放进 `.card::before` 的**光斑**里 → 完全落在"彩色光斑"授权内（底座原本就有紫 + 绿两枚，加一枚青碧是同类扩展）✅。
- 把青碧当作**功能性能量色**铺到 12 个锚点（LED 语义、liveBar、积分、发送键、主行动、选中态）→ **超出"光斑"**。这不是氛围，这是**第二个功能性彩色主角**。旧的 `#7f77dd` on 白 = **3.76**（≈ 品牌紫、且白底不可辨）确实该换，所以换色的**动机成立**；但"引入青碧"实质是把用户原话的「紫 + 光斑」扩成了「紫 + 青碧 双彩色系统」，**属于对用户定义的扩张，需用户确认**，不能由设计内部默认生效。

**② 青碧(192°) 与品牌紫(265°/53° 距) 同屏是否会"两个主角竞争"稀释品牌紫？**
—— **有中等风险。** 青碧明亮、冷、chroma 高；品牌紫 `#534ab7` 更深更闷。在浅玻璃卡上，**青碧会被视为主行动色（发送/保存/liveBar），体积上可能压过紫**，导致"主行动是青碧、身份才是紫"，对品牌的"紫"反而被推成背景色。
**建议给青碧设硬上限：**
- 青碧**饱和面积 ≤ 紫色面积**；青碧只做**细边 / 光斑 / 小锚点 / 单个主行动填充**，**任何青碧铺层面积 > ~2000px² 时必须 ≤ α.24，绝不允许实心**（spec 目前 liveBar 走半透明 ✅）。
- **紫独占**身份/导航/选中/大面积（用户气泡、`.setnav-i.on`、chip `.sel`）；**青碧独占**进行/能量（liveBar、灯、积分、发送）。
- 记录一处**角色渗漏**：`.themecard.on` / `.pinned:hover` 用青碧表达"选中/悬停"，而 `.setnav-i.on` 用紫——但与 t1 的处置一致（t1 同样用琥珀表达面板内选中），属可接受的"分区角色"，需在文档写明。

**③ 擦线标注是否成立？**
- "图形/边 3.77 ✅" → **成立**。
- "`#12a5b8` 灯 2.96 ⚠️ 仅作发光点、不单独承载信息" → **不成立，需修正**。通道活跃灯是**状态指示器**（回答"这个通道开没开"），**它就是承载信息**，必须 ≥3:1。→ 灯芯改 `--energy`(#0e8fb0, **3.77**)（t3），不要用 `--energy-bright`。
- "青碧内描边 α.55 ≈2.1，装饰性" → **部分成立**。当作 `.card::before` 的白内描边 / 玻璃装饰边时成立；但**一旦用在 `.send` / `.row2 button.pri` 上，它是"主行动按钮的边界"，就不是装饰了** → 主行动边界必须 ≥3:1（见新增 C）。

**必须修正项：**
1. **需用户确认**：t3 引入青碧这一扩张（或退回到"青碧只进光斑，function 色另议"）。
2. **阻断**：t3 `.led.on` 灯芯 → `--energy`(#0e8fb0, 3.77)，不用 `--energy-bright`。
3. **阻断**：t3 `.send` / `.row2 button.pri` 的边界从 `rgba(青碧,.55)`(2.02) → 实心 `--energy`(3.77)（填充仍保持半透明玻璃，见新增 C）。
4. 青碧面积/强度上限按 ② 执行（饱和面积 ≤ 紫；铺层 >2000px² 时 ≤ α.24，禁实心）。

## 全局无障碍清单

- **文字对比**：浅底最大系统性问题是 `--fg-muted`(3.23) 与基类硬编码 `#888780`(3.61) —— 本次新增能量层**放大了**它。建议浅色两套统一引入 `--fg-quiet`，把所有"次要正文"（`.who/.sys/.slotnote/.slothead.hint`）从 `--fg-muted` 迁走，`--fg-muted` 只留给真正的装饰元素（分隔线、`.typing i` 圆点等）。
- **图形 3:1**：灯 / Orb 轨 / 主行动边界是本次的三大擦线区，均已在上面给出修法。
- **共享令牌契约**：`--energy-edge` / `--energy-soft` 在 t1/t2 是**不透明**色，在 t3 却是 **alpha**（.55 / .14）→ **同一 token 在三套里语义不等价**（t3 的 `--energy-edge` 天然 <3:1）。建议 t3 拆出**不透明**的 `--energy-edge-solid:#0e8fb0`(3.77) 供功能性边界用，alpha 版只作装饰。
