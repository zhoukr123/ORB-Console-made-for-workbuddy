📦 可选组件 需联网下载
本地离线识别（ASR）是干什么的 把说话的声音转成文字，顺带读出语气 装它：语音输入、录屏/会议录音的文字稿都能在本机转写 —— 完全离线、音频不出机器、不用填 Key。用的是 SenseVoice，一次识别同时给出文字、语种、情绪和声学事件（笑声/掌声/背景音乐），所以看视频时还能知道"那句话是什么语气"。
不装：语音输入会回落到浏览器在线识别（要联网，而且在 Electron 里常常连不上），其余功能都照常。
和「看视频」的关系：画面理解（抽帧）不需要它；装上之后除了拿到台词，还会多一层情绪。
和「录屏字幕」的关系：装上它，录屏模块才能一键识别录屏里的对话、自动生成字幕（再校对、落盘成 .srt/.ass 软字幕，或烧进画面成硬字幕）。没装时录屏字幕功能仍完整可用，只是得自己手写 / 粘贴台词，不能自动识别。
CodeBuddy CLI（后台 Agent） 专有软件，无法代下载 · 装完需登录 官方安装：npm i -g @tencent-ai/codebuddy-code（需 Node.js 18.20+）或 PowerShell irm https://www.codebuddy.cn/cli/install.ps1 | iex
字幕烧录（ffmpeg） GPL 软件，无法代下载 · 没有也能用软字幕 干嘛的：录屏字幕默认生成为「软字幕」（.srt + .ass 外挂，视频一字节不动）；想要字幕直接烧进画面（发给别人、传平台、投屏时不必再挂字幕文件），需要 ffmpeg 来合成。
不装：照样能生成软字幕，只是点「确认并烧录」时会提示"本机没有 ffmpeg"，不影响其它功能。
装法：winget install ffmpeg（推荐，自动进 PATH）；或官网 https://ffmpeg.org/download.html 下载 Windows 版 zip，解压后把 bin 目录加进 PATH。装完去「设置 → 录屏」重新检测即可，不用重启。
