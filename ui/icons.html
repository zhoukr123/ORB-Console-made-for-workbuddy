五、自检清单（改完逐条过）

1. 面板底是白色 #FFFFFF，所有图标线色必须是深色（紫 #3C3489 / 灰 #5F5E5A / 红 #D8443F）
2. 急停是红圈 + 斜线，不是横置胶囊、不是八角警示框
3. 设置是同心圆双环 + 八条放射线，颜色深灰 #5F5E5A，不是齿轮、不带红色徽标
4. 录制是红色实心三角（fill，无 stroke、无外框），高度必须 17.2（M5.4 3.4 → 19.4 → 5.4 20.6），不能缩回旧值
5. 顶栏描边保持 2.3，不要降到 1.9
6. 图标尺寸 18px，容器 29px
7. 圆角统一：容器 7px、Logo 6px
8. 红色只出现在录制三角和急停圈线两处
9. 固定是图钉（斜 45° 钉身），不是心形、不是图钉加号
10. 固定动效是针端向外位移，不是整体缩放、不是旋转
11. 录制动效的圆环是顺时针（rotate 正方向），且必须淡出不能硬切
12. 所有动效只允许动 transform / opacity，必须带 prefers-reduced-motion 降级
13. 检查对比度：任何线色对白底必须 ≥ 3 : 1，#CECBF6 类浅色一律不可用
