## 05 作品介绍（不少于 30 字）

可直接粘贴（约 420 字，涵盖使用场景 / 目标用户 / 核心功能 / 体验方式）：

```
ORB 控制台是一个 Windows 桌面 AI 员工：它不给你操作建议，而是自己在你的屏幕上动手。

【解决什么】
让 AI 帮忙时，你得先截图、粘贴、再用文字描述"那个按钮在右下角"，它回你一段步骤，最后还是自己点。
ORB 把这段来回砍掉：你只说一句话，它自己截图看屏幕、判断该点哪里，然后替你点击、输入、滚动，做完把过程回给你。

【核心功能】
· 三条轨道自动分流：前台轨道直接操作鼠标键盘；后台轨道把重活派给本机 CodeBuddy CLI（答案边跑边长出来）；视觉轨道"截图→判断→动作→再截图"闭环，坐标用千分比不用像素。
· 工作流录制与回放：录一遍即可重复；界面改版了也不怕——可配"照坐标继续 / 停下来报错 / 先问一次视觉模型 / 交给智能体顶几步"四档兜底。
· 录屏与截屏：录屏可只录一块（半屏 / 中间 / 自定义框选），摄像头小框跟着录制区域走；截屏唤起本机 Snipaste 框选标注。
· 长期记忆：七层结构，规则与偏好常驻，项目与教训按需检索；超量自动压缩瘦身，原文归档不删、可回溯。
· 声音与个性：360 句离线语音随包带（不联网、不耗额度）与在线合成两条并行音源各有关关；五个人格各有台词与问候，台词同时以气泡显示在对话里。

【目标用户】
每天在多个软件窗口之间做重复点按的运营、测试、财务、行政同学；以及需要 AI 读本地代码库、跑本地命令的开发者。

【安全】
Ctrl+Alt+Backspace 一键急停；只读 / 工作区可写 / 完全访问三档权限；前台动作有观察边框；本机接口全部带随机令牌；零遥测，密钥只在内存里过一遍。

【体验方式】
打开介绍页 → 下载 Windows 便携版（211 MB，双击即用，不装 Node/Python）→ 说一句"打开记事本，写一句 Hello"即可看到它自己动手。
后台轨道需本机已安装并登录 CodeBuddy CLI；前台、视觉、录屏、截屏不依赖它。项目以 MIT 开源。
```

一个真的会替你操作电脑的 Windows 桌面 AI 员工：说一句话，它自己截图看屏幕、判断该点哪里，然后替你点击、输入、滚动，做完把过程回给你。三条轨道自动分流，可录制工作流重复执行，录屏能只录一块，长期记忆会自动瘦身；还能选五个人格、只听不联网的离线语音。
