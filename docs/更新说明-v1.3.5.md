# v1.3.5 更新说明

距 v1.3.0 之后做了一轮全面检修和性能优化，集中在稳定性、性能和几个明显的功能问题上。下面分开说，末尾附按模块归类的详细修复清单。

## 控制台不再占任务栏

之前一打开主面板，Windows 任务栏就会多一个 ORB 的图标，Alt+Tab 里也会出现。现在面板不再进任务栏，应用身份交给右下角的托盘图标：左键开/关面板，右键菜单里有「打开面板 / 划词自动弹出 / 打开控制台页面 / 退出」。

提醒一句：因为不再进任务栏，Alt+Tab 里也找不到它了，唤出请走托盘、悬浮球右键或全局快捷键。托盘图标第一次可能被 Windows 收进「隐藏的图标」折叠区，去设置里把它拖出来固定即可。

## 工作流跑起来能看到进度了

之前点「运行」之后，只有头像在转，进度条自始至终不出现，你不知道卡在第几步、还要等多久。现在运行条会正常显示，每一步都有反馈。

## 录屏和截图更省心

- **录完更省电**：之前录屏结束，那条悬浮控制条的计时器会一直空转（哪怕窗口已经藏起来），悄悄占着 CPU。现在结束立刻停。
- **短录制不留垃圾**：之前录了一秒就停，临时文件删不掉，得等一天后的启动清理才消失。现在直接清掉。
- **连续截屏两张都在**：之前同一秒连按两次截屏，后一张会覆盖前一张。现在文件名带毫秒，连按也各归各位。
- **做两次前台动作后 CPU 会正常回落**：之前「观察 / 前台」模式有个计数漏洞，连续开两次就只关得回一次，边框和前台追踪会永久空转。现在做了去重，开几次就能关几次。

## 截屏用自己的界面能截到了（顺手加固）

录屏进行中、以及抓玻璃底图那一瞬才排除 ORB 自己，其余时间随便截——这一版把「排除」从开关改成了引用计数，修掉了并发录屏时「先结束的那一路把排除撤掉、导致你再也截不到 ORB 自己」的隐患，同时把录屏失败时多减一次计数、面板被强关 / 超时回收 / 放弃录制这几条复位路径都补齐了。

## 主题与样式修了几处「看不见」

- 白昼主题下，设置面板的按钮悬停、输入框聚焦的描边之前整条规则被一个写错的选择器（连续两个逗号）废掉了，现在恢复。
- 深色主题下，错误提示用的红色字压在深底上几乎看不清（对比度只有约 2:1），现在走主题令牌，清晰了。
- 视觉循环里的步骤文字、中断按钮之前写死浅色，深色主题下浅字压浅底，现在也跟着主题走。

## 自定义渐变更跟手

设置里调自定义渐变时，整页配色之前每拖一下把手就重算一遍整篇文档样式，快速拖动会卡顿；现在整页令牌做节流、预览条每帧更新，拖动顺了。松手后面板配色与预览条一致，收起色卡也回到已保存的渐变。

## 后台任务与回复落盘更稳

会话存档之前是每次改动都把整份会话列表全量写一遍盘（后台任务每两秒的进度、长回复每片都算），高频又费劲。现在磁盘写入做了合并（400 毫秒内的多次改动只落一次盘），关窗口前会强制落盘，既不丢数据也不拖慢界面。

## 其它修掉的稳定性和数据问题

- **偏好不再整份静默回默认**：之前设置写入是直写目标文件、失败就悄悄吞掉，写坏一次主题 / 存储根 / 最近录屏全丢且无察觉；现在改成先写临时文件再替换，失败有日志。
- **存储根选上级目录不再卡死**：之前选到当前存储目录的上级，会卡在「有旧数据待搬迁」的死结里出不来。
- **语音停止更可靠**：之前点停时偶发麦克风实际还在录、界面却显示已停；现在收尾竞态修掉了。
- **实时字幕窗首帧不再空白**：之前首帧拿不到主题令牌，个别配置下会一直看不见。
- **原生录屏（MP4）超时与异常更稳**：子进程超时、连接断开会正确回收，不再留孤儿。
- **命令面板回车更准**：之前过滤后回车执行的不是最佳匹配项（把事件对象当成了「保留选中」标记）。
- **外链与协议闸**：打开外部链接、语音识别端点都加了协议白名单，避免把内部地址或密钥带出去。
- **桥的本地数据改用可写目录**：之前用户级配置、积分累计、回调日志等落在安装目录，打包版（装目录只读）会静默失效或归零；现在统一落到数据目录，老数据升级时兼容读取。
- 桥的状态文件改用原子写，强杀 / 断电不再把危险工具清单、白名单、积分累计等写坏归零。

## 已知问题

没有代码签名证书，第一次双击时 Windows SmartScreen 会拦一下，点「更多信息 → 仍要运行」即可。

本地语音识别的模型仍是按需下载，没下也能用（走云端那条路）。

## 下载

发布页两个文件，挑一个：

- `ORB控制台-1.3.5-便携版.exe`——单文件，双击即用，首次启动解压到本机。
- `ORB控制台-1.3.5.zip`——完整目录，不想多占一份解压空间选这个。

都不用装 Python、Node 或别的运行库。

## 第一次打开

会先过一遍首跑向导，前台、语音、视觉、后台四条通道逐条体检，能用的会打上勾。想用截屏先装 Snipaste；想用后台长任务，装 CodeBuddy CLI 并登录。拿不准的时候记住 `Ctrl + Alt + Backspace` 是急停，随时能打断。

## 详细修复清单（按模块）

下面按模块列出本次全部修复与优化，供排查与回溯。每条约 `[严重度] 文件 — 现象 / 修复`。

### 主进程 `main.js`

- **[高] 录屏结束，控制条计时器永久空转**：`rec-cmd-to-bar` 的 `stop` 分支只复位 + 隐藏，从不广播 `rec:event`。控制条窗 `backgroundThrottling:false`，隐藏也不节流，250ms 走时定时器烧到窗口销毁。修复：补 `emitRecEvent(payload)`。
- **[高] 退出留孤儿进程**：`fgStop()`（常驻 orb-foreground.exe 探针）与 `stopSnipPoll()`（600ms 截屏态轮询）定义后从未调用。修复：`will-quit` 补调用。
- **[高] 截屏排除被先结束的会话撤销**：`setCaptureShield` 是布尔开关，而录屏允许 3 并发、原生链路并行，先结束那路会撤掉排除。修复：改引用计数；并补齐 `cap-abort` / 超时回收 / 面板强关 / `will-quit` 四处复位；原生启动失败路径不再重复减计数。
- **[高] 短录制临时文件删不掉**：`cap-close` 先删会话再按 id 找 → 取到 `undefined`，`unlink` 根本没跑。修复：短内容分支直接 `unlinkSync`。
- **[高] 观察态引用计数泄漏**：主进程 `observing` 是 +1/-1 计数，渲染层 `stopObservingSoon` 只有一个定时器句柄——两次 `true` 只换回一次 `false` → 计数归零失败 → 边框定时器（800ms）与前台轮询（500ms）永久空转。修复：渲染层加 `setObservingOn()` 做 0→1 / 1→0 去重，再次请求 `true` 时只取消待关定时器（续期）。
- **[中] 偏好整份静默回默认**：`saveState` 直写目标文件、`catch{}` 全吞，写坏一次即回默认且无察觉。修复：tmp + rename 原子写 + 失败日志。
- **[中] 录制文件名路径穿越 / 非法字符**：修复：`safeFileName()` 清洗，文件名只留安全字符；`uniqueFile` 内 basename + startsWith 双保险。
- **[中] 状态标量不收敛**：写坏的 `"pinned":"false"` 会让面板永久钉住且 UI 改不回来。修复：`loadState` 补 `normalizeScalars()`，相关字段按 `===true` 收敛。
- **[中] 外链无协议闸**：`open-external` 接受任意 scheme。修复：仅放行 `http/https`。
- **[中] 主题名拼进 `executeJavaScript`（注入点）**：修复：主题名走 `THEME_IDS` 白名单 + `applyToolbarTheme` 改 `JSON.stringify`。
- **[中] 启动链无 catch**：一步失败静默吞掉整条启动链（没球没面板没快捷键，仅一行 unhandledRejection）。修复：`.then` 补 `.catch`。
- **[中] 录屏分片同步写卡主线程**：`cap-chunk` 每片 `fs.writeSync`。修复：改 `async` + `await fs.write`，循环补齐部分写入，**严格串行**（顺序错一个字节 MP4 box 全错）。
- **[低] ASR 端点无协议闸**：会带用户 Bearer Key 发出去。修复：加 `http/https` 白名单。

### 渲染层 `panel.html`

- **[高] 工作流运行条从不出现**：`#liveBar` 显示分支写 `style.display = ''`，被样式表 `display:none` 接管 → 显示分支形同死代码。修复：改 `'block'`。
- **[高] CSS 6 处非法选择器 `,,`**：选择器列表出现空组件，浏览器丢弃**整条规则**。影响白昼 / 自定义主题下 `.more-btn` / `.pinned` / 按钮 `.pri` / `input:focus` 的悬停与焦点样式；其中一条本是用于修 `.slotnote .muted` / `.sheet .note` 硬编码 `#888780` 对比度的覆盖——等于白写。修复：清除 `,,`。
- **[中] 命令面板回车执行非最佳匹配**：`input` 直接把 `renderCmd` 当监听器，Event 被当成 `keepSel` 实参（恒真）→ 每次打字走「保留上次选中」分支。修复：`addEventListener('input', () => renderCmd())`。
- **[中] 9 处内联 `color:#a32d2d` 改令牌**：深空主题下对比度约 2:1 看不见。视觉循环步骤项 `#e8e6df` / `#5f5e5a`、中断按钮浅底无字色一并改令牌。
- **[中] 消息区反复被拽回底部**：后台任务 2 秒一刷无条件 `scrollTop = scrollHeight`。修复：加 `nearBottom()` 贴底判定。
- **[中] 切会话 200 次强制布局**：`addMsg` 在 `silent`（历史重建）时仍滚动。修复：重建时跳过滚动，由 `render()` 末尾统一滚一次。
- **[中] 自定义渐变拖动卡顿**：整页 20 个 `--iris-*` 令牌每次拖拽都全量重算样式。修复：`gePreview` 拆成 `gePreviewBar`（每帧）+ `gePreviewTokens`（整页，60ms 节流 + rAF 补最后一帧）；`geAfterSet(live)` 按是否拖拽决定节流。
- **[低] 预览拖拽每帧重算舞台尺寸**：修复：一次拖拽只算一次（`pvGeom`，`pointerup` 清空）+ `pvRenderNextFrame()`（rAF 合并）。
- **[低] 发送 / 附件键高光的 `left` 过渡**：每帧重排。修复：改 `transform: translateX`（与 `left` 等价、纯合成）。
- **[低] 自定义色卡收起说谎**：原来直接 `geClose` 会把未保存渐变留在 `<html>`。修复：走 `geCancelEdit`，收起回到已保存渐变。
- **[低] 危险清单 chip / 积分警示块硬编码色**：改 `var(--danger)`。
- **[优化] 会话落盘去抖**：`save()` 每次全量过 IPC 写整份会话列表（≤20 会话 × 4KB）。修复：磁盘写入合并（400ms 内的多次 `save()` 只落一次盘），localStorage 即时写保留，页面卸载前 `flushSave()` 强制落盘。

### 小窗与 `preload.js`

- **[中] 字幕窗首帧令牌全空**：令牌挂 `html[data-skin="dark"]`，文档初始无该属性 → 首帧拿不到 `--pill-bg` / `--fg`。修复：挂到 `html`；靠底对齐替代居中；当前行改用下标判（对象引用会重复标 `cur`）；✕ 按钮文案改实话；补 CSP。
- **[低] 录屏控制条拖动窗口刷日志**：`pointerdown` 全量打印。修复：加 `DIAG` 开关；页面命中区补 `HIT_PAD=8` 与主进程 `REC_HOVER_PAD` 对齐。
- **[低] 悬浮球 breathe/bob 缺双兜底**：补 `html.no-motion` 与 `prefers-reduced-motion`。
- **[低] preload 订阅绕开订阅表**：`onRecCmd` / `onSubCfg` 用裸 `ipcRenderer.on`，重复注册无法解绑。修复：走 `on()` 订阅表（签名等价，渲染层收参不变）。

### 桥 `bridge.mjs`

- **[高] 状态文件直写覆盖，写坏即归零**：危险工具清单 / 白名单 / 触发器 / 积分累计 / ASR 配置 / 子进程台账 / 工作流 / 令牌共 8 处（后补 `/api/rec` 落盘）直写目标文件。修复：抽 `writeJsonAtomic()`（tmp + rename）统一替换；读取对损坏文件保留 `.bad` 而非吞掉。
- **[高] 进程树未回收**：CLI `execFile` 的 `timeout` 只杀父进程，孙进程变孤儿；HTTP 断开不取消。修复：`killProcTree()`（win32 `taskkill /PID /T /F`），在回调判 `err.killed || err.signal` 时收整棵树。
- **[高] 装目录不可写**：用户级配置 / 积分累计 / 回调日志 / OCR 临时图写在安装目录，打包态（Program Files 下）只读 → 静默失效或归零。修复：统一落 `DATA_DIR`；`confFlag` 先读 `DATA_DIR` 再回退 `HERE`；台账 / 积分**读时回退旧位置**（老版本升级不丢数据）；回调日志 >1MB 砍半。
- **[中] 第二个实例覆盖令牌**：启动未探测已有实例，会覆盖令牌文件 → 主进程拿新令牌问旧实例全线 401。修复：`existingBridgeAlive()` 加端口一致性判断（pid 会被复用，复用会误判）。
- **[中] 端口占用静默失败**：修复：EADDRINUSE 显式退出并提示。
- **[中] daemon 子进程漏登记**：急停收不掉、变孤儿。修复：进 `registerChild` / `trackProc`。
- **[低] `wb-models` 强刷并发**：「更新」钮连点会并发 spawn 多个 147MB CLI。修复：在途复用 + 10s 最小间隔。

### 打包 `pack.cjs`

- **[高] 发布版配置静默失效**：`approvals.json` / `danger-tools.json` 只放包根，打包态 `DATA_DIR` 是 `%APPDATA%`，`ensureBundledExtras` 只认 `resources/extras/` → 发布版回落内置默认。修复：两份配置同时拷到 `resources/extras/`。
- **[中] 中文 / 空格路径经 cmd 转码失真**：`execSync` 拼命令字符串。修复：`robocopy` 与 `tar` 改 `spawnSync` 参数数组（保留 robocopy 1–7 成功语义）。

### 暂缓（本轮未做）

- `/api/vlm` 的 SSRF 协议闸（自建视觉端点，一刀切会挡正常地址）。
- 请求体超限回 413 + `req.destroy()`（需先确认无合法大负载接口）。
- `get-state` 里 4MB 主题背景图改按需返回（需渲染层联动）。
