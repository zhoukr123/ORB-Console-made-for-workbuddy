# v1.5.0 更新说明

这一版给个性系统补上了它一直缺的那半截：**台词不再全是写死的**。开着「AI 台词」之后，它说的话由模型按当前人格现编，跟着任务真实进度走；不想花这份钱就关掉，一个字都不多花。顺带，你可以填自己的接口来生成这些话，不必占用 CLI 的额度。

然后是一个原本被我划在「不做」里的东西：**那个自定义接口现在能接管后台任务了**——你在设置里填的模型，可以真的去读文件、跑命令、干活。多出来的消耗也一并记在账上，不再是一笔看不见的支出。

另外把「元气小太阳」和「开心果」并成了一个人格。

## 一、AI 台词：现编的，但不是瞎说

以前所有台词都来自台词库：每个情境三句，随机挑一句。好处是零成本、绝不出错；坏处是听多了就那几句，尤其「完成」这一档，跑十个任务能听到同一句话三次。

现在多一个开关（**设置 › 个性 › AI 台词**），默认关。打开之后，每派一个任务会**多一次模型调用**——注意是一次，不是每句话一次。这一次调用会把整轮要用的话一次性生成好：

- **过程三句**：任务执行中说的，跟着真实进度放出来；
- **收尾一句**：成功、失败各有一版。

也就是说，成本等同于「结尾现编一次」，但整个过程都有这个人格自己的说法。

### 关键在分工：事实归程序，措辞归模型

这是这一版最需要说清楚的一件事。模型在生成这些话的时候，**并不知道你的任务里发生了什么**——它只看到你输入的那句话。如果让它自己编「我正在读 config.js 第 42 行」，它一定会编，而且编得很像真的。

所以这条线划得很死：

- **什么时候说、说到第几句、说的是「哪一类动作」——由程序根据真实的工具调用决定。**
- **这句话具体怎么措辞——由模型按人格决定。**

具体做法是把工具名映射成人格能说的泛化动作：读文件 / 搜代码是「翻箱子找东西」，改文件是「动笔」，跑命令是「拧螺丝」，认不出来的就**不说**。宁可少说一句，也不说一句假的。

另外三条限制也在里面：最多三句、同一个工具不重复念、两句之间至少隔六秒。任务跑两分钟不会被十二句话糊满，跑五秒也不会来不及开口。

### 关掉就是一键回到从前

没配接口、接口挂了、超时、模型返回一堆废话解不出 JSON——**任何一种失败都静默退回预定台词**，你看到的就是旧行为，不会弹错误、不会空场。

「关掉就等于没这个功能」这件事是当作验收标准做的：开关关着的时候，一次额外调用都不会发生。已生成的台词和预定台词也不会连着说两遍——有现编的收尾，就没有预定那句。

## 二、自定义模型：填自己的接口，后台任务也能走它

**设置 › 通道 › 后台 Agent › 自定义模型**，或者在模型下拉里选「自定义 API…」，都会弹出同一个窗：名称、接口地址、模型名、API Key、还有一个「接管后台任务」的开关（默认开）。任何 OpenAI 兼容的 `/chat/completions` 都行。

### 后台任务怎么就能走它了

上一版我在这个位置写过「它只负责那句话怎么说，不接管后台任务」，理由是后台任务要读文件、跑命令、操作界面，纯文本接口替不了。这个判断只对了一半：**真正在做工具编排的从来不是控制台，是 CodeBuddy CLI**。

所以我换了个做法：把你的接口**注册进 CLI 自己的模型清单**（`~/.workbuddy/models.json`），派任务时把 `--model custom-local:<你的模型名>` 交给它。CLI 拿这条记录去调你的接口，读文件、跑 shell、调 MCP、急停、审计、危险操作确认——全是它在做，一样没少。控制台只在开跑前写一条记录，跑完把用量收回来。

另一个方案是自己写一套工具循环去接你的接口，我没选：那样能干的事只会更少，还得把急停、审计、危险确认重接一遍，出问题的地方也多一倍。

### 三条使用上的硬要求

**模型名必须和接口文档写的一模一样**，大小写、斜杠都算。原因很实在：CLI 会把清单里那条记录的 `id` 原样当请求体的 `model` 发出去，中间不做任何转换。所以「名称」随便起，「模型名」不能改。写错了接口会回「模型不存在」，弹窗里会这么告诉你，不会沉默。

**接口要支持 function calling（工具调用）**。这是接管任务的前提，不支持就只能生成台词。开关关掉就是这个意思——它只负责说话，不碰任务。

**Key 不进渲染层。** 提交之后写进主进程的一个配置文件（Unix 上顺手设 0600），面板再读回来只有「有没有」和后四位。真正发请求的是桥接层自己读那份文件，明文 Key 因此既不经过页面，也不走本地 HTTP。留空保存表示「不修改」，只换模型名时不用重填。

### 动别人配置文件这件事，规矩定得很严

那份 `models.json` 是你的东西，里面可能还有你自己配的模型。所以：

- **只增删 `vendor` 是「ORB 控制台」的条目**，你自己那些一个字段都不碰，顺序也不动；
- **文件读不懂（不是合法 JSON）就拒绝写入**，宁可这次任务失败，也不赌一把——半个 JSON 写回去，你的模型清单就没了；
- 写之前留一份 `.orb-bak`，原子写，不留半截文件；
- 字段没变就**不写盘**，不然每派一次任务都在动你的配置；
- 你的清单里已经有一条**同名**模型时，不再加一条重复的，而是把冲突讲清楚（下面「已知问题」里有这条的后果）。

**「测试」是真发请求。** 点它会用你填的东西生成一次真实台词，把生成出来的收尾句直接显示在弹窗里——通不通当场知道。测通之后会顺手把它注册进去，弹窗里会显示注册成的模型名（`custom-local:你的模型名`），这时候它就是真的能接管了。

弹窗本身做了主次：保存是实心主按钮，取消和测试是普通按钮；悬停浮起 1px、按下缩到 96%，和工具栏的手感一致；`html.no-motion` 或系统「减少动态效果」打开时，这些动效全部收掉。「接管后台任务」那个开关是枚小胶囊，开着是实心、关掉是描边，点一下切换，状态不许靠猜。

## 三、消耗算在一起：台词那笔也在里面

以前状态条只显示「用了几个工具、花了几秒」，花了多少 token 是看不见的。现在多了一段：**合计 token 数，以及其中台词占多少**。

比如 `▶ 后台任务 · 3 个工具 · 12.4s · 13.1k tok（台词 680）`——括号里那截就是人格现编台词额外花的。走自定义接口时前面还会标一个「自定义」，一眼就知道这次不是花 CLI 的额度。

「积分」弹窗里多了**每条任务的用量明细**：输入多少、输出多少、台词多少、成功还是失败。用自定义模型跑的任务会去掉 `custom-local:` 前缀只显示模型名，也没积分记录——因为花的是你自己在那家服务上的额度，不是控制台的积分。

两件事值得单独说：

**台词和任务是两个并发请求，谁先回来不一定。** 所以台词那笔要么并进当前任务，要么补给刚结束的那条（两分钟内），不会张冠李戴记到下一个任务头上。

**台账只保留最近 20 条，全 0 的记录不留痕。** 失败的任务也记，但标个 ✗——失败了照样烧 token，不能假装没发生。

还有一处旧提示顺势修掉了：以前「派过任务但积分没涨」一律提示「CLI 未登录」。现在多了一种正常解释——你走的是自定义模型，本来就不该涨积分。所以只在你**确实没用自定义模型**时才这么提示。

## 四、六个人格变五个

「元气小太阳」和「开心果」合并成 **元气开心果**。

原因很实在：这两个原本都站在「高外向」这一格，语言参数天然趋同——句短、感叹号多、爱用颜文字。写台词库时我已经在文档里标注过「这两个最容易生成得一模一样」。与其硬掰出差异（掰出来的差异一定很假），不如合成一个，把「高外向 + 高宜人」这一格坐实，和其余四个彻底分开。

合并后的人设有三条要守的线，都来自正经研究，不是拍脑袋：

- **幽默只用「亲和型」和「自我提升型」**。攻击型（讽刺、阴阳）和自我贬抑型（一直自嘲）属于有害象限，后者还有实证关联：持续自贬会让旁边的人产生「我在欺负它」的负担。
- **不许说「别想太多」「开心点」「这有啥好气的」**。这类淡化和指示式回应会让对方的积极情绪下降；有效的是承认这件事确实让人难受。
- **你真难受时立刻收起全部玩笑**，只做两件事：承认情绪、表明在场。切换之后十分钟内不再回到玩笑——不然下一句又蹦起来，比不安慰更伤。

老配置里选过「开心果」的会**自动迁移**过来，不用手动改。这一步必须做在合法性校验之前，否则白名单会把它判成非法值、静默退回温柔守护者，你只会觉得「设置被重置了」，而且查不到原因。

## 五、顺手修的几处

- **拿不到模型清单时，「自定义 API」入口不见了**。以前 `/api/wb-models` 一次没返回，下拉整个是空的，连配台词模型的入口也一起没了。现在拿不到清单**不清空已有选项**（避免一次抖动把列表刷没），但自定义入口一定补上。
- **久坐提醒抢在任务结果前面**。完成一个任务时如果正好该提醒了，原来是「你快长在椅子上了…」先说、再报「搞定了」。现在反过来，结果句在前、提醒在后。这句提醒的计时起点是 0，所以**每次启动后的第一个任务完成时必然响一次**，不是 bug，但顺序别扭。
- **「测试」按钮失败时给不出原因**。它只看外层「桥有没有执行」，模型自己报的错（Key 错、地址错）被吞成「接口无有效回复」。现在两层分开看，错误原因照原样显示。

## 已知问题与还没做的

- 没有代码签名证书，第一次双击时 Windows SmartScreen 会拦一下，点「更多信息 → 仍要运行」即可。
- **AI 台词的过程句只按工具类型说话**，不说具体文件名、行号。真的想让它在过程中报出「正在改 login.js 第 42 行」，需要把工具参数也喂给模型——那会让这一次调用变大，也需要额外的一道「别把路径念出来」的过滤，暂时没做。
- **接管后台任务要求接口支持 function calling**。不支持就只能当台词模型用（把开关关掉即可）。另外「看图」不走这条线：自定义模型在清单里一律声明为不支持视觉，否则 CLI 会把截图丢给看不见图的接口，然后整轮沉默失败。要让后台看屏幕，仍走「设置 › 视觉模型」那条独立通道。
- **同名模型的取舍**：你自己的清单里如果已经有一条同名模型，控制台不会覆盖它，也不会再加一条重复的——CLI 是按名字找第一条，重复只会让「到底用哪条」变得不可预测。这种情况下弹窗会把冲突讲明，但真正生效的仍是旧那条。
- **纯 CLI 那条兜底路径不报 token 用量**（`--output-format text` 模式只给正文）。所以极少数排障情形下你会看到「有积分、没 token」，不是没记账，是那条路本来就取不到。
- 回放依旧是一次性的：开始之后没有逐步进度回报，要等它跑完。
- 悬浮球的磨砂背景只在面板隐藏时自动刷新；开着面板时它背面内容变了不会跟着更新，需要手动刷一下。

- **注册器单测（71 条，全过）**：把 `models.json` 写坏一次就够用户喝一壶，所以每条边角都钉住了——首次注册的字段齐全、用户条目与未知字段一字不动、字段没变时不写盘（字节与 mtime 都不动）、换 Key 重写而不是加重复、换模型名清掉旧条目、文件是坏 JSON 时拒绝写入且原始字节不变、`.orb-bak` 备份、模型名两端空格掐掉但斜杠大小写原样保留、同名冲突不重复写入并给出警告、同名且地址 Key 一致时静默复用、不支持工具调用 / 没填 Key / 模型名空三种情况各自拒绝、`baseUrl` 已带 `/chat/completions` 不重复拼、`{models:[...]}` 外壳形式按原样写回。

## 第一次打开

会先过一遍首跑向导，前台、语音、视觉、后台四条通道逐条体检。想用截屏先装 Snipaste；想用后台长任务，装 CodeBuddy CLI 并用「打开登录脚本」登录一次。拿不准的时候记住 `Ctrl + Alt + Backspace` 是急停。
