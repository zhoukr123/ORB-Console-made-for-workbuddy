# v1.5.0 更新说明

对标 **v1.4.5**（v1.4.6 / v1.4.7 / v1.4.9 是内部迭代，没有单独写说明）。

先说清楚这一版有多大：桥侧后端模块从 **7 个变成 102 个**，单元测试从 **0 个变成 122 个文件**，
面板主脚本拆出了独立的样式表、插件页脚本、自动化页脚本，验收脚本从「跑一次 selftest」变成 **9 道门禁**。
所以这一版不是「加了几个功能」，是**把底座换了**，下面按主线讲清楚。

三条主线：

1. **多了一条不碰键鼠的通道** —— 直接指挥浏览器读页面、开页面、点按钮，不再依赖「截图 + 猜坐标」。
2. **从「内置能力」变成「能装东西的平台」** —— 插件能拖进来、能装市场里的、能被验收闸门卡住。
3. **干活之前先过治理** —— 四档治理矩阵、专家团、自动化能预检 / 断点续跑 / 回滚。

## 一、浏览器：一条不碰键鼠的快车道

以前让它「去某个网站看看」，只有一条路：截图 → 视觉模型找坐标 → 点。慢、易错、还要占着鼠标。

这一版加了一条真正意义上的快车道：**面板 → 本机桥 → 原生宿主进程 → 浏览器扩展 → 标签页**。
装一个扩展（`orb/browser-extension/`，解包后加载），面板就能直接读当前页正文、开新页、点元素、输入、滚动。

### 它能做什么、不能做什么，是硬编码的白名单

不是「什么都能干」，是**只认这 17 条**：

| 类别 | 命令 | 说明 |
| --- | --- | --- |
| 读 | `tab.list` `tab.url` `tab.title` `browser.info` | 你在开哪些标签页、当前在哪、扩展版本 |
| 读 | `dom.get_page_text` | **整页正文**（新增，见下） |
| 读 | `dom.get_visible_dom` `dom.get_text` `dom.get_attributes` | 可见 DOM 树 / 单节点文本 / 节点属性 |
| 写 | `tab.open` `tab.goto` `tab.back` `tab.forward` `tab.reload` `tab.focus` | 开、跳、后退、前进、刷新、切焦点 |
| 写 | `dom.click` `dom.type` `dom.scroll` | 点、输入、滚 |

写操作**必须显式带 `params.confirm === true`**，不带就拒（`confirm-required`）。
`cua.*` / `cookie.*` 整个家族、`eval` / `upload` / `submit` / `script.execute` 及其子命名空间**永远拒绝**——
不给「任意 JS 执行」留任何后门，哪怕将来有人误加白名单也不放行。

### 取正文为什么要单开一条命令

最早想用「把每个元素的 `textContent` 拼起来」凑正文，实测不可用：父元素包含子元素，正文会被重复 N 遍；
内联 `<script>` / `<style>` 也会一起进来，于是「提取网页文字」提取出一堆 `function(` 和 `{display:flex}`。

所以新增了 `dom.get_page_text`：用 `TreeWalker` **只走可见文本节点**，跳过 `script/style/noscript/template`，
带块数统计与截断标记。实测某高校官网首页：**1112 字 / 96 个文本块，`function(` 与 `{display` 命中数都是 0**。

### 读一下页面，不在你的标签栏留痕迹

早期版本「接管」标签页时会顺手 `chrome.tabs.group` 建一个 ORB 分组、改标题改颜色。
问题是：**只是让它读一下当前页的文字，标签栏却冒出一个分组**，这是侵入。

这一版把分组逻辑整个删掉（不留开关——留着就迟早会有人再打开），只登记所有权用于急停后的清理；
老版本遗留的 ORB 分组仍然会在急停 / 关通道时被拆掉。

### 两个浏览器都装扩展时会抢消息

真机踩到的坑：Chrome 和夸克都装了扩展，`tab.open` 稳定超时，`tab.list` 时好时坏。
根因是每个浏览器会各起一个原生宿主进程，而桥侧的待发队列是唯一的——谁先轮询谁把整条消息取走，
取走的那一方如果没有对应的扩展连接，扩展侧会**静默丢弃**（连错误都不回），桥侧只看到「没收到回执」。

修法是给队列加上归属：宿主带自己的实例标识，`channel_open` 从哪个宿主转发上来的就记在哪个宿主名下，
投递时按 `channel_epoch` 归属分发。老宿主不带标识时退回「谁取都行」的旧行为，不破坏兼容。

## 二、插件：从「内置几个」到「能装东西」

v1.4.5 之前，能力是写死在代码里的。这一版把它拆成四层：

| 层 | 干什么 |
| --- | --- |
| `pluginHost` | 协议底座：一个插件怎么声明自己、怎么被调用 |
| `pluginPack` / `pluginEcosystem` | 本地包拆包落盘、「把插件包拖进来」的后端、跨生态摄入 |
| `pluginMarket` | 插件市场的**只读离线索引**（真实数据，不联网、不编条目） |
| `pluginArtifactGate` | 生成物验收闸门：插件产出的东西要过纯逻辑校验才算出结果 |

面板里新增「设置 › 插件」页：已安装 / 市场两个分栏，搜索、筛选（全部 / 内置 / 自定义）、
启用停用（面板级）、详情展开（标识 / 输入 / 输出 / 保真度 / 状态）、自检、卸载；
下面是**拖拽安装区**（`.zip` / `plugin.json` / `SKILL.md` / 整个文件夹）和**导入声明区**（粘贴清单 JSON，先校验再安装）。

当前本机实测：已安装 2 个内置插件（正则流水线、二维码生成），市场索引 **647 条 / 6 个来源**。

> 插件执行体是同进程 JS，需要控制台构建期内置。危险能力（network / 写盘 / shell）必须显式审批，
> 控制台不会把任意代码注入运行中的进程。

## 三、治理：四档矩阵，专家团和 Max 是两个正交开关

以前只有一个「权限三档」，「要不要多花点力气把事办好」这件事没地方表达。这一版把它拆成两个开关：

| 档位 | 专家团 | Max | 启用的治理层 |
| --- | --- | --- | --- |
| 普通（默认） | 关 | 关 | 无 |
| 普通 + Max | 关 | 开 | 无（Max 只放大单 agent 并行强度） |
| 专家团（轻量） | 开 | 关 | 轻治理：代价路由 / 文件化信道 / 证据标注 / 亲测验收 / 协作红线 / 家规 |
| 专家团 + Max（满血） | 开 | 开 | 轻治理 + **重治理**：独立复核评审 + 多 agent 带上下文 |

硬约束：**没有团队就没有任何团队治理**。Tier A（独立复核评审）严格绑定「专家团 + Max」，
Tier B（轻治理）绑定「专家团」，不看 Max。这条是刻意写死在 `governanceCore.mjs` 里的，不允许被「优化」掉。

配套补的还有：

| 模块 | 解决什么 |
| --- | --- |
| `epoch`（能力时钟） | 给「一次副作用」签发 capability，执行前后校验是否仍属当代。避免换代期间老指令继续生效 |
| `policyTransition` | 策略换代状态机：先投递收敛通知，待在途工单跑到安全检查点再提交换代。**不触发即时终止**，和带外急停完全正交 |
| `ticketControl` | 急停与引导：全局暂停只挡新工单，正在跑的不硬杀（硬杀会留半截状态） |
| `receipts` | 效果收据：幂等键绝不重复发，结算落结果，中断要能被认出来 |
| `outcomeEvidence` / `outcomeSuggest` / `autoOutcome` | 结果判定不能靠模型说「我做完了」：先收界面证据，再定判据，最后独立判定 |

## 四、自动化：从「录一遍放一遍」到「扛得住改版、跑坏了能回滚」

v1.4.0 给工作流加了「遇到意外怎么办」四档策略，这一版把**运维侧**补齐了：

| 能力 | 面板位置 | 说明 |
| --- | --- | --- |
| 编排查看 | 自动化页 | 步骤图可视化、`graph-validate` 校验环路与悬空引用 |
| 回放前预检 | 自动化页 › 预检 | 开跑之前先查：目标窗口在不在、锚定文字还找不找得到 |
| **断点续跑** | 自动化页 › 运行历史 | 一条配方跑一半失败，可以从检查点接着跑，不用从头再来 |
| 配方版本 | 自动化页 | 每次改动留版本，能看 diff、能回滚 |
| 运行账本 | 自动化页 › 打开历史 | 每次 runId / 步骤 / 耗时 / 结果 / 失败分类都在账上，不补零不编数 |
| 回收站 | 自动化页 › 回收站 | 删掉的配方进回收站，能恢复；过期才清 |
| 触发器与升降级 | 自动化页 | 定时 / 文件 / 热键三类触发器集中管理；`autoPolicy` 按成功率与代价自动升降档 |
| 失败分类与有限重试 | 后台 | `autoRetry` 按错误类型判断「值不值得重试」，幂等键相同的不重复执行 |

界面上一句话概括就是那句小字：**「录一次，之后由事件自己点火」**。

## 五、外部检索：默认关闭，失败绝不悄悄降级

新增 `searchProvider` / `searchL4` / `searchOrchestrator` 一条外部检索通道，三条原则：

1. **默认关闭**。不开就一次请求都不发。
2. **凭据绝不外泄**（`searchCredentials` 默认 inert，日志里不带 key）。
3. **失败绝不静默回落到截图 / 视觉循环**。检索没成就是没成，要明确告诉你，而不是偷偷换条路假装成功。

配套 `siteLibrary`：把**你自己的浏览痕迹**变成最快的「站名 → 官网」解析器。
实测「湖南大学」→ `https://www.hnu.edu.cn/`，置信度 0.95，来源标记 `history`（本地历史，不是猜的）。
没有把握时不硬猜，交给后台走检索。

## 六、存储：一个根、按类型分、按天分层

v1.4.5 的存储是散的：录屏在 `recordings/`、截图在 `screenshots/`、导出在别处、日志又在另一处。
这一版收敛成**一个用户可见的存储根**：

```
ORB存储/
  recordings/   screenshots/   vidx/     exports/   ← 成品，按 <kind>/<日期>/<文件名>
  archive/<日期>/                                  ← 归档：搬进来的东西还在这儿，只是不碍眼
  logs/<日期>/                                     ← 运行日志按天分层
  governance/   history/   misc/
```

约定：**存储根下只允许上表这些目录**，不允许出现根级 `<YYYY-MM-DD>` 日期目录
（历史包袱曾经有过，按天堆了一层，后来统一收到 `archive/<日期>/` 下）。

迁移器 `migrateLayout.cjs` 三条原则：**默认只复制不删除**（源文件一律留着）、
目标已存在同名文件就跳过不覆盖、登记表 `rel` 旧形改写为新形且同 id 去重——**重复跑幂等**。

## 七、面板：拆壳，不再往一个文件里堆

`panel.html` 的内联主脚本一度接近两万行，15 个测试文件以它的文本为契约，改一行都心惊。
这一版开始拆：

| 文件 | 内容 |
| --- | --- |
| `panel.css`（4103 行） | 全部样式与主题令牌 |
| `pluginSettings.js`（1104 行） | 插件页：已安装 / 市场 / 拖拽安装 / 导入声明 |
| `automation.js`（1040 行）+ `automation.css` | 自动化页、运行历史抽屉、治理三卡 |
| `pdf-page.js` / `attach-probe.js` / `searchProbe.cjs` / `mdEscape.cjs` | PDF 逐页处理、附件探针、检索探针、Markdown 转义 |

原则是「新功能一律写到独立 JS，不再往 `panel.html` 里堆」，而不是推倒重来——
推倒重来会把那 15 个以文本为契约的测试一起废掉。

设置页现在是 11 栏：外观 / 视觉模型 / 语音 / 截屏与录屏 / 自动化 / 安全 / 通道 / 存储 / 插件 / 关于 / 个性。

## 升级须知

1. **数据不会自动搬**。第一次启动会问你要不要「搬过来」；也可以先跑一次离线迁移脚本（只复制不删除）。
2. **浏览器扩展必须手动重新加载**。Chrome / 夸克 / Edge 都不会因为磁盘上的扩展文件变了就重读脚本，
   浏览器里跑的一直是内存里那份旧的。所以每次更新（或改过扩展代码）都要去扩展页点一次「重新加载」，
   否则你会看到两种典型症状：新方法报 `method-denied`，或者**已经修好的行为又回来了**。
   这一版给扩展脚本加了个构建戳 `BUILD`，`browser.info` 会把它报回来 —— 拿它和磁盘上的值对一眼，
   就知道浏览器里跑的是不是旧副本。
3. **老版本留下的标签页分组**：这一版不再新建 ORB 分组；历史分组在急停 / 关通道时会被拆掉。
4. **插件是新增的独立开关**，不装不影响任何原有功能。

## 已知限制

- 浏览器通道目前只覆盖 Chrome 系（含夸克 / Edge 等 Chromium 内核），Firefox 未适配。
- 同时开多个装了扩展的浏览器时，命令按 `channel_epoch` 归属投递；跨浏览器的「接力」不做。
- 插件执行体必须在控制台构建期内置，运行时不能注入新的可执行代码（这是安全约束，不是缺陷）。
- 插件市场是**离线只读索引**，不在面板里联网拉取详情。
- 发布物仍未签名，首次运行会有 SmartScreen 提示。
