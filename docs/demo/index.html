01 / 它是怎么干活的

输入一句话，看它一步步动手

下面是 ORB 前台执行时的真实过程回放：截图 → 视觉模型给出坐标 → 点击 → 输入 → 完成。 换个句子再跑一次，节奏完全一样。

给它一个任务 / 点示例可直接填

打开记事本，写一句 Hello ORB 把桌面最新的截图拖进文件夹 打开设置，找到关于页面

演示为脚本化回放，用于说明执行流程；真机上这些动作由视觉模型 逐帧决策，坐标用 0–1000 千分比表示，避免高分辨率下数错位置。

02 / 三条执行轨道

同一句话，它自己判断该走哪条路

也可以手动指定。三条轨道覆盖"手上的活"和"动脑的活"，失败会自动切备选模型。

🖱️

前台轨道

直接操作你的电脑：点击、输入、快捷键、滚动、长按、拖动。原生 C 写的鼠标原语，不走合成事件。

适合：打开软件、填表单、整理文件
🧠

后台轨道

把重活派给本机 Agent（headless 一次性执行），跑完自动回填结果，不占你的桌面。

适合：读代码库、写长文档、跑批处理
👁️

视觉轨道

「截图 → 视觉模型 → 动作 → 再截图」的闭环，模型自己决定下一步点哪里，没有 API 的软件也能驱动。

适合：只能靠看的软件、跨应用的流程
03 / 它会动你的鼠标，所以先给了急停

把鼠标交给 AI，你第一个问题一定是这个

安全不是附加功能，是 ORB 的第一功能。以下每一条都已经在代码里，不在计划里。

急停

Ctrl + Alt + Backspace 一键中断， 顶栏也有红色急停按钮。随时可打断，不留后台动作。

权限三档

只读 / 工作区可写 / 完全访问，随会话保存。 不开「完全访问」就不会有视觉循环。

观察边框

前台执行时，被操作的目标窗口会亮起一圈边框 —— 你能实时看到"它正在操作谁"。

人工确认

删除、支付、发送等不可逆操作，模型必须先发起确认，60 秒不点自动拒绝。

令牌鉴权

桥进程每个接口都要进程启动时随机生成的令牌， 只监听 127.0.0.1。浏览器里的任意网页遥控不了你的电脑。

零遥测

项目不含任何遥测。密钥只在内存里过一遍，不落盘、不写日志。

05 / 功能一览

除了替你动手，还有这些

悬浮球交互常驻置顶；悬停展开、单击固定、拖动换位并记忆、拖出屏幕收纳成细签
对话式操作输入框按内容自动分流前台 / 后台，也可手动指定
划词即用拖拽划选文字，工具条自动弹出（搜索 / 翻译 / 发给 Agent）
语音输入麦克风按钮流式转写，引擎可插拔（Web Speech 或自建 Whisper）
录屏原生直出 MP4（1080p / 30fps），悬浮控制条可暂停、取消、完成
截屏唤起本机 Snipaste 框选标注，截图统一归档到你的存储目录
视觉闭环千分比坐标 + 主动缩放 + 主力模型失败自动切备选
首跑向导首次启动自动体检四条通道，逐条给出可用状态
06 / 下载

双击就能用

208 MB
自解压便携单文件 · Windows 10 / 11 x64
  • 运行后自己展开到 %LOCALAPPDATA%\ORBConsole，不需要安装
  • 不写注册表，不用预装 Node / Python（运行时随包自带）
  • 数据目录 %APPDATA%\ORB 控制台，卸载脚本一键清掉
  • 也可以下载 zip 便携包，解压后直接运行
去 Releases 下载 看源码

首次运行会弹 SmartScreen（项目尚未购买代码签名证书）， 选「更多信息 → 仍要运行」即可。三条证书路线的评估写在仓库 docs 里。

首次使用，三步

  • 1 设置 →「视觉模型」，填接口地址、模型名、API Key（没有 key 可选「自检」预设）
  • 2 状态条右侧滑轨选权限，日常用「工作区可写」
  • 3 直接说：「打开记事本」「截个图」「把这段整理成文档发到桌面」
