# v1.4.5 更新说明

这一版有三条主线：**声音拆成两条路、记忆会自己瘦身、录屏只录一块**。
另外把面板和本机桥之间那条链从「轮询」换成了「推送」，顺手补上了「首字延迟」这个一直缺的尺子。

> 版本号说明：1.4.3 / 1.4.4 是内部迭代，没有单独发布。这一版从 v1.4.2 直跳 v1.4.5，
> 下面写的就是 1.4.2 之后到你手上为止的全部改动。

## 一、声音：拆成两条并行音源

以前「声音」只有一个开关，开了一起开、关了一起关。问题是这两件事根本不是一回事：

- **离线语音包**——360 句台词已经提前生成好，随包带着（约 9 MB）。不联网、不消耗额度，点开就有声。
- **生成播报**——在线 TTS 接口现念，或者退回系统语音。它覆盖面广（模型现编的句子也能念），但要联网。

所以这一版把它们拆成「① 离线语音包」和「② 生成播报」两个独立开关，总开关之下四种组合自己挑：

| 离线语音包 | 生成播报 | 包里有的句子 | 包里没有的句子 |
| --- | --- | --- | --- |
| 开 | 开 | 播离线包 | 回落生成播报 |
| 开 | **关** | 播离线包 | **静默不出声** |
| 关 | 开 | 走生成播报 | 走生成播报 |
| 关 | 关 | 不出声 | 不出声 |

第二行是这次真正解锁的能力：**只留离线包，一句都不联外网**。代价是模型现编的那些句子（带任务名、带具体措辞的）没声音。
不过台词气泡照旧显示在对话里，所以你不会漏掉它说了什么——只是听不见。

开关下面有一行实时说明，直接告诉你此刻哪条音源在出声、哪些句子会没声音，不用自己推。

**顺带补上了在线语音合成接口**（这是早先答应过的东西，之前一直没交付，这次补上）：
「设置 › 个性 › AI 在线语音合成」里可以填任何 OpenAI 兼容的 `/audio/speech` 端点——地址、Key、模型名、音频格式、默认音色，
还能给五个人格各指定一套音色与语气。不配也能用，引擎停在「浏览器 / 系统语音」时这些字段是收起来的。

> 一个实测出来的小结论：语气指令**别写长**。5 个字指令约 3.17 字/秒，写到 32 个字掉到 1.09 字/秒，音色还会暗下去 570 Hz 左右。
> 一句话越长，念得越慢越闷。音色该交给音色选项和参照声线，不该靠长句子描述。

## 二、记忆：分层取用、有预算、会自己瘦身

### 分层不是为了分类好看

记忆现在是七层：`soul` / `user` / `rules` 常驻注入，`project` / `fact` / `lesson` / `topic` 按当前任务检索 top4。

为什么值得分？我们拿 18 条查询实测过：**分层和一大坨平铺，命中率完全一样，都是 18/18**。
差别在别处——平铺方案里「规则 / 偏好 / 人格」命中 **0 条**。因为检索只会挑和查询词相关的，
而「别用 tab 缩进」「回答说人话」这种规则永远不含查询词，纯检索必然把它挤掉。

所以分层的价值不是「搜得更准」，是**让不含查询词但必须在场的东西在场**。

常驻层还加了个 1200 字预算上限：按重要度、再按更新时间逐条填，装不下的丢尾，末尾补一句「另有 N 条长期记忆因篇幅未注入」。
以前是无条件全量注入，120 条规则的一次注入要 3749 字；现在 1389 字，命中不降。

### 会瘦身（新）

记忆越攒越多，全塞进上下文既贵又吵。现在它会自己压：

| 机制 | 怎么定 |
| --- | --- |
| 什么时候压 | 单层活跃字数 ≥ 6000，或全库 ≥ 14000；也可以手动点「压缩」 |
| 压哪几层 | 只压 `fact` / `lesson` / `topic` / `project`。规则、偏好、人格**永不参与**——合并有丢约束的风险 |
| 先压谁 | 重要度最低的先压；同重要度里最旧的先压；同条件下内容长的优先 |
| 压不动怎么办 | 压完缩不到原字数 55% 就整单作废，原文一条不动。没缩多少还换掉等于白丢细节 |
| 原文去哪 | 标「已归档」：退出召回、不占预算，但内容和归档原因留着自己看，90 天后才物理清理 |
| 出错了呢 | 冷却 10 分钟；连续失败 3 次自动停手，不再反复烧额度 |

「记忆库」标题旁边现在直接写清 `共 N 条 · 约 N 字 · 已归档 N`，压缩进行中会在这行提示。

顺手补了两个基础件：召回命中时真的累加 `access_count` 与 `last_accessed_at`
（此前这两列只在插入时写一次 `null`，之后从不维护，等于无法判断哪条真被用过），
以及自动记忆从「每完成一个任务就多跑一次模型」改成**攒到你停手 90 秒后批量提炼，一次最多 3 条**，队列落盘不丢。

## 三、录屏：只录一块

以前只能整屏录，一大半是无关桌面。现在「设置 › 截屏与录屏 › 录制区域」可以挑：
全屏 / 左半屏 / 右半屏 / 上半屏 / 下半屏 / 中间（70%×70%）/ 自定义框选。

两个细节决定它准不准：

- **存的是相对主屏的比例，不是像素**。改分辨率、换缩放、拔副屏之后，「左半屏」还是左半屏。
- **比例到像素的换算只在主进程做**（主屏尺寸 × scaleFactor）。面板拿到的是 CSS 像素，采集要的是物理像素，差一个缩放倍数——
  算错的表现就是「以为录左边，成片是中间」。所以渲染层只传 0..1 的比例，一律不碰 DPI。

原生直出这条路把范围交给 `orb-cap.exe --rect`（奇数边长向下取偶，编码器要偶数）；
走 MediaRecorder 那条没法裁剪，改成 canvas 逐帧 `drawImage` + `captureStream(30)`，
用 `setInterval` 而不是 `requestAnimationFrame`——录制时面板是收起的，rAF 会被系统节流到几乎停摆。

顺带修的还有两件：

- **录屏 / 截屏时隐藏控制台**这个开关，之前被放在「通道」页（跟录屏八竿子打不着），现在搬回「截屏与录屏」页顶部。
- **自定义框选的覆盖层接上了主题令牌**。它压在桌面上，底色必须恒深（浅色浮层遇上白窗口就看不见），
  但强调色跟面板同一支（`--ac-rgb` / `--ac-on` / `--accent-grad` 三件套），深空下是蓝、极光下是渐变紫，不再出现「面板一套色、浮层另一套色」。

### 摄像头小框：坐标系换成「录制区域」

小框以前是按整屏归一化的，一旦只录半屏，摆好的位置就跑到画面外。现在它的四个数
（中心点 `bx/by`、宽高 `bw/bh`）**全部以录制区域为分母和原点**，可摆放边界、吸附目标、最小尺寸也跟着录制区域走——
选「右半屏」之后小框自然待在画面里。

设置里能调的也一次给齐：形状（圆形等比缩放 / 圆角矩形 / 方框，后两种可拖边调宽高）、
比例（16:9 / 4:3 / 1:1 / 自由，或自定义长宽比）、以及「预览摆位」——
在整屏上按真实比例拖动、拖边缩放，切形状与比例即时生效，**看到的就是成片的样子**。
摆位层和录制区域框选层共用同一套主题令牌，切主题不会闪成另一套配色。


## 四、后台：推送代替轮询

面板和本机桥之间原来是定时问「好了没」。现在换成 SSE 推送：`/api/events` 推全局状态、`/api/job/:id/stream` 推单任务片段，空闲时一次请求都不发。
面板不可见时自动退回轮询——后台标签页里 SSE 会被掐，硬撑不如老实退。

这条链上修掉了四个真 bug，其中两个是会让人怀疑「这软件坏了」的：

- 新链路其实**从未生效**（一个 `await` 漏了），所以「改成推送」这件事之前只是纸面上的；
- 空状态帧被当成「没事发生」忽略掉，导致流断开后自动重连陷入死循环、气泡永远卡在「后台执行中」。

另外补了**首字延迟**（TTFT）：状态行直接显示「首字 1.2s」，审计面板顶部给近 30 次的 p50 / p95。
总耗时只能告诉你「慢了」，说不清慢在哪一段，所以必须有分位数。

## 五、几处归位

小改动，但找得到才算交付：

- **AI 在线语音合成**放进「设置 › 个性」的声音卡下面（原来在「语音」页，跟声音开关分居两处）；
- **录屏 / 截屏时隐藏控制台**搬回「设置 › 截屏与录屏」页顶部（原来在「通道」页）；
- **记忆管理**在「设置 › 存储」页：注入开关、自动提炼、项目锚定、手动添加、记忆库与压缩键都在那一块。

## 下载

发布页两个文件，挑一个：

- `ORB-Console-1.4.5-portable.exe`——单文件，双击即用。
- `ORB-Console-1.4.5.zip`——完整目录。

都不用装 Python、Node 或别的运行库。包里约 9 MB 是离线语音包，装完开口就有声。

## 第一次打开

会先过一遍首跑向导，前台、语音、视觉、后台四条通道逐条体检。想用截屏先装 Snipaste；
想用后台长任务，装 CodeBuddy CLI 并用「打开登录脚本」登录一次。拿不准的时候记住 `Ctrl + Alt + Backspace` 是急停。

## 已知限制

- **离线语音包只覆盖台词库里的 360 句**。模型现编的句子（AI 台词功能生成的）靠生成播报，关掉它就没声音。
- **记忆压缩要走后台任务**，没装 CodeBuddy CLI 就压不了——它会安静跳过，不会报错也不会卡住。
- **自定义框选目前只针对主屏**（换算基准是主屏尺寸）。副屏整屏录制没问题，跨屏框选不支持。
- **发布物仍未签名**，首次运行会有 SmartScreen 提示，点「更多信息 → 仍要运行」。
