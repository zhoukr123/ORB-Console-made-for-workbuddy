# v1.4.2 更新说明

这一版只做一件事的分量，但它在你天天会碰的那条链上：**派任务别再干等，截屏别再卡 fifteen 秒**。另外顺手把几个一直拖着的性能点压了下来。

## 一、派任务：答案边跑边长出来

以前派一个后台任务，面板就停在「后台执行中… N 秒」，要等整轮跑完才一次性把答案甩回来——几十秒里你对着一行占位符，不知道是卡了还是在干活。

现在改成**流式回传**：CLI 一边生成正文，面板那行气泡就一边把字填进来，像有人在实时打字。后台任务还是同一个（CodeBuddy CLI 跑工具、读文件、查资料），只是把「已经写出来的部分」不时回传给面板，不再憋到结尾。

落在数字上：任务跑 40 秒，你大概第 2 秒就能看到开头在长，而不是第 40 秒才看到全部。体感上的「反应速度」不在一个量级。

万一这条新链路出问题，设 `ORB_WB_TEXT=1` 一键退回旧的整段回传，行为和以前完全一致——新增的东西永远有退路。

## 二、截屏：一个藏了很久的根因被修掉

之前点「截屏」明显超过 6 秒，慢得不对劲。查下来不是 Snipaste 慢，是主进程里一个判定写错了：它把探针的**查询应答**误当成「就绪握手」吞掉，于是「截贴板基线」永远取不到。后果有两个，一个比一个糟：

- 每条查询都撞满超时，点下到浮层就绪要 **14.9 秒**；
- 基线取不到就**直接放弃本次截屏**，截图一张都不存。

现在按「应答里**没有 id** 才算握手」来判（探针只有启动那一行没有 id），查询应答正常投递，截屏回到亚秒级；还顺手把「基线取不到就放弃」改成了降级链——**序列号 → 内容指纹 → 才放弃**，探针真挂了也能靠「剪贴板里出现了和基线不一样的图」把图存下来，不会再静默丢图。

## 三、几处固定开销压下来

都是关键路径上的纯等待，砍掉不影响任何功能：

- 截屏基线查询超时 1500ms → 600ms（探针应答是 0.2ms 级，600ms 已是三千倍余量）；
- 「Snipaste 是不是已经在框选」的探测 3 次×60ms → 2 次×40ms（没在框选是常态，那 120ms 是纯白等）；
- Snipaste 运行态记忆的存活时间 1.5s → 8s，避免你**下一次**点截屏时记忆已过期、又 spawn 一次 `tasklist` 白等一两百毫秒。

## 四、随这一版固化的几样

这几样上一轮就在做了，这一版随版本一起发出来：

- **取词在工具栏常驻**，鼠标位置缩成图标；
- **打开文件夹走系统文件夹对话框**（以前只能开控制台所在的目录）；
- **两阶段 OCR 取词**：先在屏幕上拖出区域，认出文字后用高亮块框出来，点一下不要的块就去掉，再确认；
- **人格语库扩容 + 标志性动作**：每个情境 4–6 句、五种人格各自的招牌动作（偷看、跺脚、点头…）用括号缀在话后，颜文字和动作不再二选一；
- **深夜先欢迎后提醒休息**：晚上刚开控制台不再一上来就说「收工」，先打招呼，过两秒再说「该休息了」。

## 下载

发布页两个文件，挑一个：

- `ORB-Console-1.4.2-portable.exe`——单文件，双击即用。
- `ORB-Console-1.4.2.zip`——完整目录。

都不用装 Python、Node 或别的运行库。

## 第一次打开

会先过一遍首跑向导，前台、语音、视觉、后台四条通道逐条体检。想用截屏先装 Snipaste；想用后台长任务，装 CodeBuddy CLI 并用「打开登录脚本」登录一次。拿不准的时候记住 `Ctrl + Alt + Backspace` 是急停。
