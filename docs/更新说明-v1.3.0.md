# v1.3.0 更新说明

距离上一个版本 v1.2.0 大约一天。这一版主要解决「录屏」的问题：现在录出来的是 MP4，可以直接发给别人看，不用再装播放器。另外加了「加号附件」，可以在消息里拖进去图片或文档。

截屏这块也重做了：框选完会停下来让你标注，能改选区、画两笔、二次裁剪；ORB 自己的界面也不再截不到了。下面分开说。

## 原生录屏（MP4）

「录屏」键开始录整屏，直接产出 MP4，1080p / 30fps / 4Mbps，不录声音。相比上一个小版本的 webm，MP4 的优势是**到处都能播**：微信、钉钉、飞书、邮件、浏览器都能打开，不用额外装播放器。

录制里可以暂停/继续。暂停期间不计入时长，也不会漏帧。悬浮控制条默认压在屏幕上沿中间，拖走也不会挡你录东西。录完的文件落到「录制」目录，文件名是 `录屏_日期_时分秒.mp4`。

## 加号附件

在发送键左边加了一个加号按钮，点一下可以选图片、文档、音视频。更简单的是，直接在聊天框里拖一个文件进去，就会变成附件气泡，和文字一起发出去。

支持的类型分四类：图片（png/jpg/jpeg）、音视频（mp3/mp4/avi/mkv）、文档（pdf/docx/xlsx）。单次最多 10 个，超过 100MB 的会提示。发出去的附件不是拷贝，而是引用原路径——适合你本地文件很多、不想占盘的情况。

图片如果大于 4MB，气泡里会显示缩略图。

## 截屏现在会停下来让你标注

上一版点「截屏」之后，框选一松手就直接存盘了——想改个选区、想画两笔再截，都做不到。这一版改掉了：框选完**不会立刻存**，Snipaste 的标注工具栏会留在屏幕上，你可以慢慢来。

工具栏上能改选区、画箭头、涂高亮、加文字、做马赛克，还能**二次裁剪**（把刚框的区域再切一刀）。改完点「复制」，图才落到「截屏」目录，文件名是 `snip_日期_时分秒.png`。按 Esc 或者直接关掉 Snipaste 就是放弃，什么都不会存。

之前那个"自动存盘"其实是想用 Snipaste 的 `--hold` 参数实现的，但那个参数是 PRO 版的，免费个人版会悄悄忽略它——于是就变成了纯自动保存。现在改成发和你按 F1 完全一样的裸命令，走的是同一条路，所以你装的是免费版也能用。

## ORB 自己的界面可以截到了

之前无论什么时候按截图键，ORB 的面板、悬浮球、字幕窗都会从画面里消失——它们被设成了"永远不进入截图"。所以你想截一张自己界面的图反馈问题、做演示素材，根本截不到。

现在改成按需处理：只有录屏进行中、以及抓玻璃背景底图的那一瞬间才排除自己，其余时间你的界面就是屏幕上的一部分，随便截。只有录屏时例外——成片里不能出现 ORB 自己。

顺带修了一处反过来的问题：录屏时按系统截图键，悬浮控制条会一起消失（它也被排除了），看着像录屏停了。现在控制条不参与排除，截屏时照样看得见它。

## 截屏的几处别扭

存储页里 Snipaste 那一栏，安装路径会挤在同一行把「去官网」顶歪，现在路径单独一行、长了会自己收住。

设置面板打开时，工具栏的「截屏」键会被遮罩挡住。改的不是把工具栏浮上来（那样它会压在设置卡片上，更难看），而是在存储页 Snipaste 那一栏直接放一个「截屏」键——你翻到那一页时才最想截一张。

截屏开始后控制台会自己缩回去——因为框选时鼠标已经移开了。现在只要 Snipaste 还在前台（不管是你从系统快捷键唤起的，还是点 ORB 的「截屏」键），面板就不会收，想重新框几次都行；等你存完盘或按 Esc 取消，它才恢复正常折叠。

截屏时 ORB 自己的窗口会从最上层让开——原来它们压在 Snipaste 的框选浮层之上，鼠标一拖就被吃掉，框不了选区。

设置面板打开时，实时字幕窗口会浮在设置卡片上面挡视线，现在它会自动让开，关掉设置再回来。

## 修掉的问题

**划词取词一直在坏。** Electron 44 把剪贴板接口整个换了形状，`readText()` 从返回字符串变成了返回 Promise，而代码里没跟着改。结果是取词拿到的是一个 Promise 对象而不是文字，`Ctrl + Alt + G`（送剪贴板）送出去的也是 `[object Promise]`。这次一并修了六处调用。

**同一张图截两次会丢一次。** 之前判断"剪贴板里的图换没换"是比字节指纹，你截了和上次一模一样的区域，指纹没变，程序就一直等，最后一张都存不下来。现在改成看 Windows 剪贴板的写入序号——只要内容被改写序号就会变，跟内容长什么样无关。

**剪贴板里本来就有图时，划词会破坏它。** 这个保护逻辑因为上面那个 Promise 问题其实一直没生效，现在恢复了：剪贴板里只有图片的时候，划词降级会主动放弃，而不是发个 Ctrl+C 把你原来的图冲掉。

**开着 Snipaste 贴图窗时，ORB 的截屏按钮点不动。** 之前判断"用户是不是正在截屏"用的是"Snipaste 有没有可见窗口"，而贴图窗、偏好设置窗这些也都会被算进去，于是程序以为你正在截屏，干脆不重复发命令——按钮看着正常，按了没反应。现在改成只认真正属于截屏流程的那两个窗口（框选浮层和标注工具栏），别的窗口一律不算。

**按了 Esc 之后控制台要锁三分钟。** 同上，"正在截屏"这个判断不准，按了 Esc 之后程序认不出你取消了，只能干等到超时才把控制台解锁。现在能第一时间反应过来。

**点「复制」之后图存不下来。** Snipaste 是先把窗口关掉、再慢慢把图编码写进剪贴板，这中间能有几秒空档。之前等得太急，空档一过就判成"用户取消了"，图就丢了。现在留足了余量，还会再确认一次剪贴板里到底有没有图。

**截完一张马上再截一张，第二张存不下来。** 两个截屏流程互相踩了对方的后台任务，第二个的监听被提前关掉。现在每个流程只管自己的事。

**截屏期间别的程序改了剪贴板，会存错图。** 比如你正框选时在别处复制了一张旧图，程序会把那张旧图当成这次的截图存下来。现在会核对内容是不是本次新产生的。

**录屏控制条有一圈黑边。** 控制条那层毛玻璃底图，原来裁的是"窗口大小的一块"，而纱层为了留出 4px 呼吸边比它小一圈，两层盒不一样大，纱的圆角外就会露出多出来的底图，看着就是一圈黑边；能量条收起时两层缩放起点还不重合，细条里会错开一条缝。现在把底图和纱层做成同一个盒、同一个缩放中心，两层严丝合缝，黑边和错位都没了。

**录屏时控制条按钮点不动。** 控制条整条都是拖窗区域，鼠标稍微按偏（尤其能量条收起以后、或者按钮那一层被缩放、命中测试算偏），Windows 就把这一下当成"拖窗口"，点击永远进不了页面——表现就是按钮没反应、窗口被拖来拖去。现在拖窗区域收窄到左侧计时块，其余地方不拖窗：按偏了最多没反应，不会再吃掉按钮的点击。

**设置面板和划词工具栏不跟主题走。** 深空（深色）主题下，设置面板的边框、输入框、按钮还停在浅色那套配色，白底深字配在深色界面上很扎眼；划词时弹出的小工具条更是一整块写死的浅色，深色桌面上就是白条配深字。现在这两处都改成跟随主题换肤，切到深空自动变深色底、浅色字。

## 清理与体积

体积还是跟以前差不多（便携版约 200MB），但内部清掉一些临时文件：探针脚本、旧构建产物不再随包。ASR 的本地识别模型还是按需下载，不会因为你没装就影响其他功能。

这一版还换了新的控制台图标——任务栏、桌面快捷方式、窗口左上角都跟着变。

## 已知问题

没有代码签名证书，第一次双击时 Windows SmartScreen 会拦一下，点「更多信息 → 仍要运行」即可。

本地语音识别的模型是按需下载的，没下也能用——走云端那条路。

## 下载

两个文件，挑一个就行：

- `ORB 控制台 -1.3.0-便携版.exe`——单文件，双击即用，第一次启动会解压到本机，大约 6 秒。
- `ORB 控制台 -1.3.0.zip`——解压出来是完整目录，不想多占一份解压空间就选这个。

都不用装 Python、Node 或者别的运行库。

## 第一次打开

会先过一遍首跑向导，前台、语音、视觉、后台四条通道逐条体检，能用的会打上勾。想用截屏先装 Snipaste；想用后台长任务，装 CodeBuddy CLI 并登录。拿不准的时候记住 `Ctrl + Alt + Backspace` 是急停，随时能打断。
