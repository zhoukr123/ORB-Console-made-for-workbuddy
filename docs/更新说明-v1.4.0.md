# v1.4.0 更新说明

这一版主要动了两块：**工作流**（录完之后怎么扛住界面改版）和**个性系统**（让选了人格真的有反应）。另外把「打开登录脚本」这个一直半残的入口修好了。

## 一、工作流：录完之后，还得扛得住改版

录制回放最容易翻车的地方不是录，是**放**：录的时候界面长那样，过两天按钮挪了位置、多了个弹窗，回放就一路点空。以前遇到这种情况只有两种结果——要么照旧坐标硬点下去，要么整个任务失败。

现在每条工作流多了两个字段：**目标**和**遇到意外怎么办**。

「遇到意外」有四档，你按这条流程的重要程度自己挑：

- **照录制坐标继续**——不调用任何模型，最快，但界面一改版就会点错地方。适合那种「点错了也没事」的流程。
- **停下来并报错**——宁可不做，也不乱点。适合会改数据的流程。
- **先问一次视觉模型**——卡住的那一步问一次模型该怎么走，问到就继续。
- **交给智能体顶几步**——让视觉模型接管一小批动作，把流程推回正轨再交还给回放。

后两档有个关键设计：**它们只在「配了锚定文字、且那句话确实找不到」的步骤上触发**，其余步骤永远走纯回放。所以你不会因为开了这个功能就每条流程都变慢——零额外成本，只在真正卡住的那一步才花钱。

### 智能接管

选了「交给智能体」之后，回放半路发现「配了锚点却找不到」，会把请求挂起来，视觉模型顶上去做一小批动作（默认 3 步，最多 12 步），做完立刻回报。

这里有个分工要说明：**判定权在后端，不在面板**。后端手上才有剩余步骤和它们的锚点，由它自己截图 OCR 判断「回没回到原轨道」；面板只负责干活和报账。这是刻意的——让面板去猜自己到了第几步，猜错就是跳步，比点错位置难查得多。

循环里还多了一层保护：接管时会明确告诉模型「你在循环内部，这是第几轮，剩下的轮次程序会自己继续」。不点明的话，模型会把这一轮当成唯一一轮，做完就报完成，父层循环整段被跳过——少做的那几轮不会有任何提示。

### 循环轮次标记

循环节点新增一个可选配置：**轮次标记**。就是圈出「每一轮都会做一次」的那个动作（点提交、点保存），并给它一句锚定文字。

界面失守时，靠数它**成功执行**了几次来推定「已经完成几轮」。数据来源是审计表——每次调工具本来就会写一条，所以零埋点、零运行时成本。它是可选的：不配也能靠视觉模型读屏自证（看「已处理 3 条」那种数字），配了就多一道客观校验，两者不一致时以自证为准并留日志。

顺带一提，步骤里如果录到了窗口锚点，现在会**显示出来**（只读），帮你理解这一步当时是认着什么做的。

### 录到重复片段，会问你要不要折成循环

录完一条工作流，如果系统发现里面有几段几乎完全相同的操作，会给一句话加一个按钮：

> 这段录制里有 3 段几乎完全相同的操作（每段 4 步），看起来是在重复做同一件事。要不要折叠成「重复 3 次」的循环？折叠后总步数从 12 步变成 4 步，以后改一处就够了。

**它不会擅自改你的结构**。录 3 段不一定是想循环，也可能就是三份内容不同的表；系统直接折了，你下次打开会看到一个自己没建过的循环，还看不懂为什么。所以做成建议，点一下才改。

### 触发器搬进工作流了

以前加触发器要去命令面板，加完还看不出它绑在哪条流程上。现在**定时 / 文件变化 / 热键直接在每条工作流的编辑面板底部管理**：列出绑在它身上的触发器，可启用、停用、删除，也能直接「+ 定时 / + 文件 / + 热键」新建。`Ctrl + K` 那个入口保留。

### 另外几处

- **列表的操作键改成图标**：回放 / 编辑 / 删除三枚图标，省下的宽度留给名字。
- **删除要输入「删除」两字确认**。以前手一抖就没了，工作流录一次不容易。
- **审计日志搬进「设置 › 存储」**：和运行记录放在一起看，不用再去命令面板翻。
- 步骤树里循环 / 判断 / 变量 / 动作四枚图标重画过，小尺寸下比原来清楚。

## 二、个性系统：六个人格，和它们的台词

设置里多了一整页「个性」。它是一个**陪伴层**，和后台 AI 的回答是两条独立的线——人格不会去改 AI 的回答内容，只是旁边有个家伙在嘟囔。

六个人格，各自有台词库、口吻、颜文字和音色：

| 人格 | 什么感觉 |
| --- | --- |
| 温柔守护者 | 慢一点、稳一点，会提醒你休息；深夜主动把声音收掉 |
| 元气小太阳 | 有精神、爱打招呼、句子短；空闲时最活跃，汇报任务时不吵 |
| 开心果 | 爱开玩笑、颜文字多；玩笑只在你不想干活时开，正经事不糊弄 |
| 上进小战友 | 把任务当共同目标，会数着步子给你打气 |
| 智慧小向导 | 讲清楚再动手、少卖萌；不确定会直接说不知道 |
| 正能量傲娇 | 嘴上不认、事情照做；被夸会躲，失败会嘴硬着再来一次 |

除了说话，**悬浮球也会跟着演**：完成、打招呼、加载、点头、害羞、思考、晚安，七张动图各自在什么时机播有明确分工；你可以整体关掉，也可以单独关掉某几张。空闲两分钟后它会从四张里随机播一张。专属行为也接上了——傲娇被夸会害羞、温柔深夜会说晚安，这些是面板指定球播哪张图，球的播放逻辑仍归它自己。

TTS 用的是系统语音（Web Speech），每个人格配了语速和音调；不想听就关，关了照样有气泡。

### 台词现在会显示在对话里

这是这一版最该说的一件事。之前选了人格，最常听到的反馈是「启用了，但没什么反应」。查下来原因很直接：**那些台词只念出来，不显示**——它们走的是语音合成，一个字都没往对话区写。所以只要你没开声音（或者没注意听），个性就等于完全隐身。

现在每句念出来的台词，都会在对话里留一条小小的气泡：比正文小一号、颜色更淡、左边一道细线，跟着当前主题的强调色走。

好处是就算你把声音关了，陪伴感也还在——以前声音一关，悬浮球之外就什么都不剩了。气泡**不进会话历史**：它是当下的一句嘟囔，不是需要回看的内容；写进历史既会污染列表，也会把会话标题顶掉。代价是切换会话时它就不在了。

### 精简念白：一个任务只念一句

以前跑一个任务，它会念三遍：收到 → 执行中 → 完成。每句两三秒，一轮下来十几秒就这么没了——而你真正想听的其实只有「完成」那句，前两句面板上本来就有状态在报。

现在默认只在**有结果、有情绪**的时候开口：完成、失败、连续失败后的安慰、被夸、里程碑（三连击、每十次）、深夜、周五傍晚、久坐提醒、空闲太久。「收到」和「执行中」省掉了。

想听回完整版，在 **设置 › 个性 › 声音** 里把「精简念白」关掉即可，随时可切。

## 三、「打开登录脚本」终于能用了

这个按钮之前有两个毛病，叠在一起的表现就是「点它，窗口闪一下就没了」：

1. 脚本里写的是直接调用 `codebuddy`，可它装在一个没进 PATH 的目录里（只有本机的 `orb/local.conf` 才指得到），所以脚本永远找不到它——登录入口其实一直是摆设。
2. 脚本放在带中文的路径下（数据目录、项目目录都是中文），系统打开这种路径的脚本会闪退。

现在它会先按和后台检测同样的顺序找到 CLI 的真实位置，把完整路径写进脚本里，再把脚本生成到一个纯英文的临时目录去打开——不再闪退，也真的能把 CLI 拉起来。万一系统那条路走不通，还有一条兜底。

（补一句背景：CLI 的登录是 OAuth 流程，令牌必须由 CLI 自己写回本地，所以这个按钮没法简化成「给你一个网页链接自己登」——网页登录只解决账号侧，后台任务仍然派不动。）

## 四、还修了几处小地方

- **空闲两分钟那张动图，以前很可能根本不会来**。它原来是一个 120 秒的定时器，靠各处"有人在用"的信号反复重排；页面一旦被系统当成后台，长定时器会被对齐到分钟级甚至挂起，而重排它的地方有七八处，真出事看不出是哪一个。现在改成只记"最后一次有人在的时刻"，另开一个 5 秒的轮询去比时间——被节流也只是晚一点，不会永远不来。悬浮球窗口也关掉了后台节流。顺带：每次跳过的原因会写进 `orb.log`（形如 `[idle] 跳过：docked`），下次再说"等了两分钟没动静"，打开日志就知道是面板开着、贴边收着还是别的。
- **动图可以直接试播**：「设置 › 个性 › 动图」里双击任意一张，悬浮球当场播一遍。空闲动图两分钟才来一次，光靠它没法确认链路通不通。
- **启动问候**：原本要求声音开着才出现，和其余台词不一致，关声时第一句问候就没了。现在统一了。
- **找 CLI 的过程改成异步**：原来那步会同步卡住主进程（最坏几秒），而它就发生在点按钮的这一下。
- **输入弹层的层级**：通用输入框现在压在所有弹窗之上。以前在工作流编辑器里弹输入，会被编辑器盖住。

## 已知问题与还没做的

- 没有代码签名证书，第一次双击时 Windows SmartScreen 会拦一下，点「更多信息 → 仍要运行」即可。
- **记忆那一档目前只记下你的选择**（项目记忆 / 会话记忆），真正去读文件还没接上。
- 回放依旧是一次性的：开始之后没有逐步进度回报，要等它跑完。
- 悬浮球的磨砂背景只在面板隐藏时自动刷新；开着面板时它背面内容变了不会跟着更新，需要手动刷一下。

## 本轮做的检查

- **悬空元素引用**：四个 HTML 里所有 `getElementById` / `#id` 引用全量比对，零悬空（这类问题曾导致「少个元素、后面整段脚本静默失效」）。
- **语法与结构**：`main.js` / `preload.js` 过语法检查；内联脚本解析零错误；标签配对无交叉不匹配（只剩一条历史误报）。
- **令牌与类名**：新增样式只用已定义的令牌，四个主题下都确认过；JS 用到的类名都有对应规则。
- **IPC 白名单**：面板 65 处 `window.orb.*` 逐个比对 preload 白名单，无越权。个性配置从面板传到悬浮球时做了白名单化——这是渲染层能写的唯一一份「会影响球怎么演」的状态，不收窄就等于让面板能往球里塞任意串。
- **逻辑测试**：新写了念白与气泡的测试（14 条），覆盖精简开启时该跳的、该念的、气泡的形态与不落盘、声音关着也出气泡、纯工具模式完全静默；既有三套测试全部保持通过（57 / 20 / 16）。
- **CLI 路径解析**：单独验证了它在本机能正确解析到真实可执行文件。

这一版**没有做真机渲染验证**：开发时本机控制台一直在运行（单实例锁会挡掉调试实例），气泡和图标键的实际观感需要你启动后自己看一眼。

## 下载

发布页两个文件，挑一个：

- `ORB-Console-1.4.0-portable.exe`——单文件，双击即用。
- `ORB-Console-1.4.0.zip`——完整目录。

都不用装 Python、Node 或别的运行库。

## 第一次打开

会先过一遍首跑向导，前台、语音、视觉、后台四条通道逐条体检。想用截屏先装 Snipaste；想用后台长任务，装 CodeBuddy CLI 并用「打开登录脚本」登录一次。拿不准的时候记住 `Ctrl + Alt + Backspace` 是急停。
