# v1.4.0 更新说明

这一版做两件事：**让个性真正看得见**，以及**把「打开登录脚本」这个一直半残的入口修好**。另外顺手把念白的节奏收紧了——以前一个任务要念三句，现在只在有结果的时候念一句。

## 个性台词现在会显示在对话里

之前选了人格，最常听到的反馈是「启用了，但没什么反应」。查下来原因很直接：那些台词**只念出来，不显示**——它们走的是语音合成，一个字都没往对话区写。所以只要你没开声音（或者没注意听），个性就等于完全隐身。

现在每句念出来的台词，都会在对话里留一条小小的气泡：比正文小一号、颜色更淡、左边一道细线，跟着当前主题的强调色走。它和 AI 的回答是两回事——**个性不会去改 AI 的回答内容**，那是另一条线，这一版没动。

这么做还有个副作用是好的：就算你把声音关了，陪伴感也还在。以前声音一关，悬浮球之外就什么都不剩了。

气泡是**不进会话历史**的。它是当下的一句嘟囔，不是需要回看的内容；写进历史既会污染列表，也会把会话标题顶掉。代价是切换会话时它就不在了。

## 精简念白：一个任务只念一句

以前跑一个任务，它会念三遍：收到 → 执行中 → 完成。每句两三秒，一轮下来十几秒就这么没了——而你真正想听的其实只有「完成」那句，前两句面板上本来就有状态在报。

现在默认只在**有结果、有情绪**的时候开口：完成、失败、连续失败后的安慰、被夸、里程碑（三连击、每十次）、深夜、周五傍晚、久坐提醒、空闲太久。「收到」和「执行中」省掉了。

想听回完整版，在 **设置 › 个性 › 声音** 里把「精简念白」关掉即可，随时可切。

## 「打开登录脚本」终于能用了

这个按钮之前有两个毛病，叠在一起的表现就是「点它，窗口闪一下就没了」：

1. 脚本里写的是直接调用 `codebuddy`，可它装在一个没进 PATH 的目录里（只有本机的 `orb/local.conf` 才指得到），所以脚本永远找不到它——登录入口其实一直是摆设。
2. 脚本放在带中文的路径下（数据目录、项目目录都是中文），系统打开这种路径的脚本会闪退。

现在它会先按和后台检测同样的顺序找到 CLI 的真实位置，把完整路径写进脚本里，再把脚本生成到一个纯英文的临时目录去打开——不再闪退，也真的能把 CLI 拉起来。万一系统那条路走不通，还有一条兜底。

（补一句背景：CLI 的登录是 OAuth 流程，令牌必须由 CLI 自己写回本地，所以这个按钮没法简化成「给你一个网页链接自己登」——网页登录只解决账号侧，后台任务仍然派不动。）

## 还修了两处小地方

- **启动问候**：它原本也要求声音开着才出现，和其余台词不一致，关声时第一句问候就没了。现在统一了。
- **找 CLI 的过程改成异步**：原来那步会同步卡住主进程（最坏几秒），而它就发生在点按钮的这一下。改成异步后不再阻塞。

## 已知问题

没有代码签名证书，第一次双击时 Windows SmartScreen 会拦一下，点「更多信息 → 仍要运行」即可。

## 本轮做的检查

- **悬空元素引用**：四个 HTML 里所有 `getElementById` / `#id` 引用全量比对，零悬空（这类问题曾导致「少个元素、后面整段脚本静默失效」）。
- **语法与结构**：`main.js` / `preload.js` 过语法检查；内联脚本解析零错误；标签配对无交叉不匹配（只剩一条历史误报）。
- **令牌与类名**：新增样式只用已定义的令牌，四个主题下都确认过；JS 用到的类名都有对应规则。
- **IPC 白名单**：面板 65 处 `window.orb.*` 逐个比对 preload 白名单，无越权。
- **逻辑测试**：新写了念白与气泡的测试（14 条），覆盖精简开启时该跳的、该念的、气泡的形态与不落盘、声音关着也出气泡、纯工具模式完全静默；既有三套测试全部保持通过（57 / 20 / 16）。
- **CLI 路径解析**：单独验证了它在本机能正确解析到真实可执行文件。

这一版**没有做真机渲染验证**：开发时本机控制台一直在运行（单实例锁会挡掉调试实例），气泡的实际观感需要你启动后自己看一眼。

## 下载

发布页两个文件，挑一个：

- `ORB-Console-1.4.0-portable.exe`——单文件，双击即用。
- `ORB-Console-1.4.0.zip`——完整目录。

都不用装 Python、Node 或别的运行库。

## 第一次打开

会先过一遍首跑向导，前台、语音、视觉、后台四条通道逐条体检。想用截屏先装 Snipaste；想用后台长任务，装 CodeBuddy CLI 并用「打开登录脚本」登录一次。拿不准的时候记住 `Ctrl + Alt + Backspace` 是急停。
