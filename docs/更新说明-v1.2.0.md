# v1.2.0 更新说明

距离上一个版本 v1.0.1 大概一周。这一版主要加了三样东西：四套可以换的主题、截屏、完整的录屏（带悬浮控制条）。另外修了几个会直接影响使用的问题，放在后面说。

## 四套主题

在「设置 → 外观」里切换，每套的配色和气质差别挺大：

**深空** 是深靛蓝底配琥珀金，晚上用不刺眼。**白昼** 是浅底配紫罗兰和青柠，白天最常见的一套。**极光·氤氲** 用浅色玻璃盖在一层缓慢流动的彩板上，能量色是兰紫；彩板本身有六种配色，糖果、薄荷、极光、黄金时刻、玫瑰石英、翡翠之城，随时能换。**自定义** 允许你放一张整窗的图片当背景，上面盖一层白纱。

每套主题的强调色可以单独改，互不影响。极光那套除了六种预设，还能自己拉一条色带生成渐变——横向选色相、纵向选明度，拖到什么颜色就是什么颜色。

毛玻璃单独开关，深空、白昼、自定义各记一份，默认关闭。打开之后面板、历史、设置、更多这些浮层会半透明，背后的桌面被糊成磨砂。极光本身就带玻璃，所以那一套没有这个开关。

## 截屏

工具区多了一个「截屏」键。按下之后会调起本机安装的 Snipaste 让你框选，选完可以继续用它的标注栏改选区、画框、写文字、打马赛克、再裁一刀，最后点保存，图会落到「截屏」目录，文件名是 `snip_日期_时分秒.png`。

这里没有自己做截图界面，是刻意的：Snipaste 的框选和标注打磨了很多年，短期内追不上。所以我只做两件事——把它叫起来，再把结果收进统一的目录。框选的手感、快捷键、你原来的使用习惯都不用改。

需要自己装 Snipaste（免费个人版，官网或者 Microsoft Store 都行）。没装的话这个键会弹一张引导卡，装好点「重新检测」就能用，不影响其他功能。

## 录屏

「录屏」键开始录整屏，直接产出 MP4，1080p / 30fps / 4Mbps，不录声音。录制中可以在悬浮控制条上暂停或继续，完成之后文件落到「录制」目录。

控制条默认压在屏幕上沿中间，可以拖走，不会挡住你要录的地方。开始录之后几秒它会自动收成一条细能量条，把鼠标移上去再展开。皮肤有灰白纱和深纱两种，描边颜色能自己挑。

暂停期间不计入时长。

## 存储位置

设置里新增「存储」一页。录制、会话历史、截图三类文件都挂在同一个存储根下面，可以整体挪到别的盘；页面上能看到已用空间、能直接打开目录，换根的时候会把旧文件一并搬过去。

## 工具栏

常用的四个键固定在面上：看屏幕、实时字幕、鼠标位置、截屏。其余收在右边的竖排三点里，悬停时三点会轻轻起伏一下，展开时转 90 度。

## 修了什么

- 前台通道偶尔拉不起来（上个小版本那个问题的延续）。
- 录屏暂停后时长算多。
- 毛玻璃开着却不模糊——窗口是透明的，取不到背后的桌面，改成自己抓一张垫在底下，再由卡片糊出来。
- 截屏选完就关，标注栏根本没出现（少了一个参数）。
- Microsoft Store 版 Snipaste 装了却提示「未检测到」。
- 主进程里一处初始化顺序写错，会让整个面板的按钮失效，已修正并加了检查。

## 下载

两个文件，挑一个就行：

- `ORBConsole-1.2.0-portable.exe`——单文件，双击即用，第一次启动会解压到本机，大约 6 秒。
- `ORBConsole-1.2.0.zip`——解压出来是完整目录，不想多占一份解压空间就选这个。

都不用装 Python、Node 或者别的运行库。

## 第一次打开

会先过一遍首跑向导，前台、语音、视觉、后台四条通道逐条体检，能用的会打上勾。想用截屏先装 Snipaste；想用后台长任务，装 CodeBuddy CLI 并登录。拿不准的时候记住 `Ctrl + Alt + Backspace` 是急停，随时能打断。

## 已知问题

没有代码签名证书，第一次双击时 Windows SmartScreen 会拦一下，点「更多信息 → 仍要运行」即可。

磨砂玻璃在拖动面板或者手动刷新背景时会闪一下，大约 0.4 秒。抓桌面那张图需要窗口短暂让开，这一步暂时绕不过。

本地语音识别的模型是按需下载的，没下也能用——走云端那条路。
