ORB 控制台 v1.5.0｜说一句话，它真的会替你操作电脑

给频道里的伙伴同步一个社区侧的新版本：ORB 控制台 v1.5.0。
它是为 WorkBuddy / CodeBuddy 生态而做的桌面 AI 助手——一个常驻桌面的悬浮球，你说一句话，它自己看屏幕、判断该点哪、替你点击 / 输入 / 滚动，做完把过程回给你。后台轨道直接调用你本机的 CodeBuddy CLI，不用另配 Key。

先说这一版的分量：桥侧模块 7 → 102，单测 0 → 122 个文件，验收从「跑一次自检」变成 9 道门禁。不是加了几个功能，是把底座换了。

[配图 1：封面]


一、多了一条不碰键鼠的浏览器快车道

以前让它「去某个官网看看」，只有「截图 → 视觉模型猜坐标 → 点」这一条路，慢、易错、还占着鼠标。
现在走的是：面板 → 本机桥 → 原生宿主 → 浏览器扩展 → 标签页。装好扩展，它就能读整页正文、开页、点元素、输入、滚动，全程不碰你的键鼠。

安全上卡得很死：只认 17 条白名单命令；eval、cookie、upload、submit 整个家族永远拒绝；所有写操作必须显式带 confirm，不带就拒。取正文专门用 TreeWalker 只走可见文本节点，不会把 script / style 混进来。只是读一下页面，也不会再往你标签栏里塞一个分组。两个装了扩展的浏览器同时开会抢消息这件事，也按 channel_epoch 归属修好了。


二、插件：从「内置几个」到「能装东西」

「设置 › 插件」里，已安装 / 市场两个分栏，搜索、筛选、启停、详情、自检、卸载都齐了；.zip、plugin.json、SKILL.md 或整个文件夹，拖进来就装，也能粘贴清单 JSON 校验后导入。市场是离线只读索引，当前 647 条 / 6 个来源，不联网、不编条目。
插件产出的东西要过验收闸门才算出结果；执行体必须在控制台构建期内置，危险能力（联网 / 写盘 / shell）要显式审批，不会往运行中的进程注入任意代码。

[配图 2：插件生态]


三、安全永远排在能力前面

它会动你的鼠标，所以急停是第一功能：Ctrl + Alt + Backspace，或顶栏红色急停按钮，一键中断前台、后台和排队中的任务。急停只挡新工单，正在跑的不硬杀——硬杀会留半截状态。
再加只读 / 工作区可写 / 完全访问三档权限、每次副作用都签发的能力时钟、桥接层随机令牌鉴权、删除 / 支付 / 发送这类不可逆操作的人工确认、凭据不进日志、零遥测、长期记忆只存本地 JSON。

[配图 3：主界面]


四、四条轨道 + 一个模式，治理四档

同一句话，它自己判断走哪条：前台（直接操作桌面）、后台（重活派给 Agent，答案边跑边长出来）、视觉（截图闭环，对付没 API 的软件）、浏览器（v1.5.0 新增）。「专家团」是顶栏独立开关：你只跟分配者对话，它把活切给工作者并行推进。
治理上，「专家团」和「Max」是两个正交开关。没有团队就没有任何团队治理；重治理（独立复核评审 + 多 agent 带上下文）严格绑定「专家团 + Max」，这条是写死的，不允许被优化掉。


五、自动化：录一次，之后由事件自己点火

开跑前预检（目标窗口在不在、锚定文字还找不找得到）、跑一半失败可以从检查点断点续跑、配方每次改动留版本能 diff 能回滚、删掉的配方进回收站能恢复、每次运行都有账本（runId / 步骤 / 耗时 / 结果 / 失败分类），定时 / 文件 / 热键三类触发器集中管理，失败按类型判断值不值得重试，幂等键相同的不重复执行。

[配图 4：自动化]


六、日常用起来更顺手

四套主题（深空 / 白昼 / 极光·氤氲 / 自定义整窗图片）共用一套语义令牌；两条音源 + 随包 360 句离线语音，不联网也能出声；录屏可以只录屏幕的一块；长期记忆会自己挑重点，也会自己瘦身，装不下会如实告诉你「另有 N 条未注入」。
所有成品收敛到一个用户可见的 ORB存储/ 根下，按「类型 / 日期」分层；迁移器默认只复制不删除，重复跑幂等。设置页现在有 11 栏。

[配图 5：四套主题]


升级前看三眼

· 数据不会自动搬：首次启动会问你要不要搬过来，也可以先跑离线迁移脚本（只复制不删除）。
· 浏览器扩展必须手动「重新加载」：Chrome / 夸克 / Edge 不会因磁盘文件变了就重读脚本，不重载会看到 method-denied，或者「已经修好的行为又回来了」。browser.info 会报回构建戳 BUILD，跟磁盘对一眼就知道浏览器里跑的是不是旧副本。
· 插件是独立开关，不装不影响任何原有功能。


几句实话（已知限制）

· 浏览器通道目前只覆盖 Chromium 系（Chrome / Edge / 夸克等），Firefox 未适配；跨浏览器「接力」不做。
· 插件市场是离线只读索引，面板里不联网拉详情。
· 发布物仍未签名，首次运行遇到 SmartScreen，选「更多信息 → 仍要运行」。
